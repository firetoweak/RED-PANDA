# 网上检索

## 搜索与正文读取

搜索负责找到来源，正文读取负责快速获取文字，浏览器负责观察和操作页面；三者可以组合使用。根据任务与已有证据决定还缺什么，不要求每次走完全部工具，也不必等检索服务失败才打开浏览器。用户对当前任务有明确要求时遵循。

先查看可用 Toolset 目录。搜索默认优先使用用户单独配置并启用的检索服务（例如 Tavily），其次使用目录中可用的 mcp:builtin-deepseek；已知来源 URL 时可以直接读原文或打开页面。按名称、说明和实际工具识别搜索服务，不要把无关 MCP 当成搜索服务。多个服务可用时，按当前任务选用，无需用户逐个确认。

加载 mcp:builtin-deepseek 后，可用 web_search 搜索、web_fetch 读取原文。需要搜索结果同时附正文时，可设置 need_content=true；已有正文足以支持回答就不用重复抓取。摘要不足以支持结论时，读取原文或用浏览器补充所缺的信息。

第一次检索取得有效结果才说明本次服务可用；目录中有能力不等于网络已连通。连接失败、超时、限流或认证失败时，按需换用其他可用服务或浏览器，不为修复某项服务阻塞任务，也不在失败的服务之间反复循环。

按工具当前参数填写查询主题、地域、时间和希望找到的来源；中文主题先用中文，技术资料必要时补英文。

## 浏览器补充

正文遗漏关键图表、图片或动态内容，需要展开、滚动、翻页才能核实，或用户希望看到页面与视觉证据时，主动使用浏览器补充。检索已成功也可以继续；目标本来就是观察页面时可以直接使用浏览器。

加载目录中可用的 mcp:builtin-playwright 或 mcp:builtin-chrome-devtools，按任务选用一项即可；需要查看网络请求、控制台或调试页面时可选后者。优先打开已经找到的来源 URL。没有来源或搜索服务不可用时，也可打开 https://www.bing.com/ 或 https://www.baidu.com/ 搜索，再访问原始页面。

用页面快照定位元素、读取文字与交互；如果快照结果是文件链接，先用文件读取工具打开它。只看到加载中时，等待目标内容出现再观察。文字快照与图片 URL 不代表已经看过图像；判断图表、布局或图片细节需要实际查看图片或截图。截图聚焦相关区域，避免无关整页反复占用上下文。能力不支持查看图像时，如实说明未核实的视觉部分。

内置浏览器不继承用户日常浏览器的登录状态。遇到验证码或访问限制，可换可访问的原始来源；确实需要用户登录时说明这一步。只使用当前目录提供的能力；缺少浏览器时保留已经查证的结果并说明缺口。

## 核实与图文交付

优先原始资料与官方页面，检查日期与适用范围。空正文、跳转提示和错误页面不能作为已核实的来源。回答附可访问的来源链接，区分原文事实与推断；不要把连接成功或搜索结果数量当作资料质量。

把信息是否充分与怎样表达更清楚分开判断。有帮助时主动配上来源图片、相关截图或基于已核实数据绘制的图表；已有材料足够时直接组织回答，无须为了配图再打开浏览器。原始图片、页面截图与自行绘制的说明图要说清来源和用途，说明图不能冒充网页证据。

使用真实工具返回的图片 URL 或文件，保留来源页面链接；本地图片按当前对话提供的文件交付方式发送，不能只给用户一个本机路径。不要编造图片地址、截图或图中的事实。证据足够、表达清楚后就停止继续抓取与截图；仍有缺口则明确说明。
