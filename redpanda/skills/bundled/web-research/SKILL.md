# 网上检索

用户指定搜索服务时优先遵循；否则加载 mcp:builtin-exa，使用它实际提供的搜索与正文读取工具。无需用户申请 Key。第一次检索取得有效结果才说明本次服务可用；目录中有能力不等于网络已连通。

用自然语言说明查询主题、地域、时间和希望找到的来源。按工具当前参数填写检索目标；中文主题先用中文，技术资料必要时补英文。优先原始资料与官方页面，检查日期与适用范围。摘要不足时读取原文；空正文、跳转提示和错误页面不能作为已核实的来源。回答附可访问的来源链接，区分原文事实与推断。

## 浏览器兜底

搜索服务超时、不可达、限流，或结果无法回答问题时，加载 mcp:builtin-playwright（也可选 mcp:builtin-chrome-devtools）。打开搜索引擎，例如 https://www.bing.com/ 或 https://www.baidu.com/，用页面快照找到搜索框并提交查询，打开相关结果阅读原文；已知官网地址时可直接访问。如果快照结果是文件链接，用文件读取工具打开该文件再选择页面元素；只看到搜索框或加载中时再获取页面快照。沿用同样的来源核实与引用要求。

遇到验证码或访问限制，可换一个可访问的搜索引擎或原始来源；仍不可用就说明受阻，并建议用户配置 Tavily 等搜索 MCP。不要无限重试，不要把连接成功或搜索结果数量当作资料质量。切换方式由你根据可见结果决定，说明哪些内容仍未核实。
