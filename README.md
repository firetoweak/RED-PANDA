**一支长期协作的 AI 团队，接上你正在进行的工作。**

你照常在 Codex、Claude Code、Cursor 等原生工具里开发。konden 提供一支有名字、能互相交流的 Bot 团队，承担独立验证与持续跟进，减少你重复说明背景、转交报告和推动下一步的工作。

每位 Bot 都有自己的持久工作目录，通过私信和群聊协作。你设定目标、决定授权，也可以随时加入讨论、调整方向。编码是当前优先做好的场景；分析资料、讨论想法同样可以开展，代码项目按需关联。

> [!WARNING]
> 项目处于快速迭代阶段，功能、界面和本地数据格式可能发生不兼容的变化。当前产品定位见[产品定位](docs/产品定位.md)，后续方向见 [Coding Bot](docs/架构/CodingBot/方向.md)。

## 从独立验证开始

写代码的智能体完成修改、自测并提交 PR 后，另一个团队从需求和真实用户操作出发验证结果：

```text
交付需求与版本 → 独立验证并取证 → 原编码会话取得反馈、修复 → 新版本复验
```

验证团队交回复现步骤、预期与实际表现、证据和实际测试版本。你可以在 Web 中查看成员的讨论与执行过程，也可以随时介入。自测和 CI 通过是参考，实际验证结果由团队另行取证。

原编码会话需要保持运行，主动等待和处理反馈。当前接入用于本机，不会在客户端结束后自动唤醒它。完整场景与边界见[产品定位](docs/产品定位.md)。

## 快速开始

支持 **Windows x64**、**Linux x64（glibc 2.35+）** 与 **macOS 15+（Apple Silicon / Intel）**。

macOS 需要可用的 Git；若系统尚未准备命令行工具，先运行 `xcode-select --install` 并完成系统安装。

```sh
git clone https://github.com/firetoweak/konden.git konden
cd konden
```

先运行准备脚本，选择与你的系统对应的命令：

**Windows（PowerShell）**

```powershell
.\scripts\setup.ps1
```

**Linux / macOS（终端）**

```sh
sh scripts/setup.sh
```

准备脚本会补齐 Python、Node.js 等运行工具，不修改系统 PATH；无需预装 Python、Rust 或 Docker。参数说明见[准备选项](docs/运行指南.md#准备选项)。

setup 完成后，先按[个人连接文件说明](docs/模型配置.md#个人连接文件)填写模型密钥。打开终端打印的「模型连接配置」文件（默认 Windows 为 `%USERPROFILE%\.konden\connections.json`，Linux/macOS 为 `~/.konden/connections.json`），在所用供应商项的 `api_key` 中填入自己的 API Key 并保存，保留其他供应商项。本地服务地址也在这个文件中配置；Codex 登录方式见[复用 Codex 登录额度](docs/模型配置.md#复用-codex-登录额度)。

填好后再启动：

**Windows（PowerShell）**

```powershell
.\scripts\start.ps1
```

**Linux / macOS（终端）**

```sh
sh scripts/start.sh
```

需要指定监听地址或端口时，在启动命令后追加 `--host 0.0.0.0 --port 8765`，用法与访问地址见[启动参数](docs/运行指南.md#启动参数)。

启动后打开终端打印的地址，在侧栏「设置 → 模型配置」中[添加相应模型](docs/模型配置.md#web-配置与会话切换)，保存后点击「测试」确认连接，再新建 Bot、说明你希望它承担的工作。需要处理代码时，再[关联已有首个提交的 Git 仓库](docs/运行指南.md#模型与工作区)。

Mac 的后台任务须保留在命令的进程组内：启动服务时使用前台模式，再由 konden 转后台；自行脱离进程组的守护程序不在自动停止范围内。

Bot 可按需使用随环境安装的 Chrome DevTools MCP、Playwright 和应用专用 Chrome，进行浏览器操作与真实流程验证。搜索优先使用你已启用的搜索 MCP，其次使用已配置密钥的内置 DeepSeek；浏览器可补充动态内容、页面交互和视觉证据，检索服务不可用时也能承担搜索。回答可结合来源图片、截图或基于已核实数据绘制的图表；配置、数据位置与其他入口见[运行指南](docs/运行指南.md)。

## 外部会话接入（MCP）

1. 打开「设置」→「外部接入」，生成连接配置，添加到原生工具。凭据只显示一次，请在关闭设置前保存。
2. 原生聊天领取自己的会话身份后，即可在 Web 侧栏「外部会话」看到它；每个新聊天领取独立身份，原聊天重连时沿用。
3. 联系长期 Bot 讨论需求、开展调查或交接工作，持续读取它们的答复与后续消息。普通交流无需代码项目或版本。

可以这样向编码智能体说明任务：

> 请通过已连接的 konden 联系同事，先讨论这个需求，保留当前聊天的身份并持续收取回复。

原生会话通过 `get_context` 登记身份、查询同事名字，用 `send_message` 发送普通消息，用 `read_messages` 按游标持续收取消息。Bot 可以主动继续发言，无需绑定某次请求。独立验证是在对话中开展的一种任务，需求、版本、证据和复验方法由[验证 Skill 与协作约定](docs/独立验证.md)承载。

连接配置可复用于多个聊天，各聊天分别领取身份。共用凭据下的身份用于分流，不提供权限隔离；外部消息也不能代你批准命令或读取无关私聊。工具调用、Web 查看与撤销方式见[外部会话接入指南](docs/外部协作.md)。
