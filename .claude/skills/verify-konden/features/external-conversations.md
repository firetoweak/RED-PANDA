# 外部会话

原生聊天经 MCP 登记独立身份，与长期 Bot 持续双向交流，并在 Web 中可见；通信契约不要求 Codex 身份或自动接续绑定。当前优先适配并验证同机 Codex，其他客户端暂未纳入接入验证。消息不要求仓库、版本或验证结论。来源：外部会话服务、MCP 入口与 `web/src/features/external/`；任务场景见用户指南 `docs/外部协作.md`。

## Sub-features

- `register`：首次 `get_context` 省略 identity，登记后即在侧栏出现，允许尚无消息；新聊天领取新身份，原聊天和重连沿用原身份。
- `duplex`：外部用 `send_message` 向同事发送正文，Bot 用 `send_external_message` 按外部 identity 发言；可引用此前消息，也可独立继续话题。Bot 用 `list_external_sessions` 查询已登记对象。
- `inbox`：`read_messages` 按外部会话和游标读取所有同事显式发来的消息，允许没有原请求；有界等待、分页与重启后续读不改变消息归属。
- `web`：侧栏“外部会话”支持搜索与过滤；进入后按 Bot 查看往返。Bot 时间线的外部名称跳到对应外部对话，外部页面可进入相关 Bot 的会话。
- `access`：「Codex 接入」优先引导用户在 Codex 应用添加 Streamable HTTP 服务器，展示可分别复制的 URL 与 Authorization 请求头值；TOML 放在「高级：手动配置 TOML」。复制值与显示值一致，关闭后不再显示凭据；撤销使该配置下全部会话停止收发。已有会话、往返与引用继续可读，页面不声称客户端持续在线。
- `codex-continuation`：人在外部会话的「Codex 自动接续」绑定聊天 ID 与本机程序；保存后新消息发送固定提醒，失败或未确认时可重试，停用与撤销停止后续提醒。入队不代表已经处理。

## How to get to it (user POV)

从“设置 → Codex 接入 → 生成连接配置”进入，核对应用内添加步骤、URL 与 Authorization 的独立复制，确认 TOML 默认收起。按指引在 Codex 应用中添加服务器；无法驱动原生设置时，明确记录该步骤未验证，不以 CLI 或协议客户端代替。高级路径可将 TOML 合并到隔离 `CODEX_HOME` 下的 `config.toml`，用本机 Codex CLI 检查配置确实可读，再通过 MCP 完成身份登记。关闭设置前保存凭据，不将凭据放入截图或证据。Codex 聊天领取身份后，从侧栏“外部会话”点名称进入；需要 Bot 回复时，先创建 Bot 并配置模型，无需代码项目。

## Driving it with the browser

先按主技能启动独立 home、端口并通过 Doctor。配置、登记与历史查看不需要模型；真实 Bot 收发和主动联系需要 live_model_ready。

生成配置必须由 Web 页面操作。外部身份登记和发言走 MCP 真实入口，HTTP GET 只核对界面结果。

1. 登记两个原生聊天：首次各省略 identity，取得不同身份；重连传原值。两项应在发送消息前实时出现在侧栏，点开显示已接入的空状态；刷新不重复登记。
2. 无版本普通往返：从一个身份向 Bot 讨论需求，Bot 显式回传，再独立补充一条不带回复引用的消息。外部按同一游标续读得到两条，Web 内容与方向一致。
3. 分流与主动联系：第二个身份联系同一 Bot，回复不能出现在第一个身份的收件箱。人在 Bot 私聊中让它查询外部会话并主动联系第一个身份，即使没有新外部请求也能送达。多 Bot 收件与跨对象引用边界在低成本契约层验证。
4. 导航与阅读：从 Bot 时间线的外部名称进入对应身份及 Bot 的过滤视图；切回全部对话。桌面明暗主题与 390px 名册、消息、引用均可读，没有横向溢出；新消息不抢走正在补读的位置。
5. 停止并重启记录的 Host，按原身份与游标续读：历史、消息号、引用和位置保持，侧栏不新增重复项。
6. Web 设置撤销配置：正在等待的读取应结束，新访问为 401；外部页面实时显示接入已撤销，原消息仍在。保存同一状态的截图、快照与只读 API body。
7. 同机 Codex 接续：在外部会话页展开「Codex 自动接续」，填入目标聊天 ID 并保存；先验证无效 ID 和程序路径的错误提示，再让 Bot 发消息。核对消息先可读取、状态随后显示入队，并在原 Codex 聊天确认新一轮启动。保持两个外部身份的绑定独立。模拟命令失败时从页面「重试提醒」，核对原消息不重复；停用后新消息继续可读但不再提醒。截图与只读会话 body 留存提醒状态，原生聊天启动记录单独保留。

## Gotchas

服务端不能自动识别原生工具切换了聊天，客户端负责在各聊天中保留 identity。共用凭据下的身份用于分流，不构成权限隔离。普通 assistant 结尾给人看，外部消息需要显式发送；送达不表示对方已处理。Codex 自动接续需由人显式绑定，当前只支持同机已加载聊天；不承诺打开应用或恢复未加载聊天。
