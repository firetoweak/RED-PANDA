# 模型配置

入口是侧栏「设置 → 模型配置」，三页为「供应商与模型」「已选模型」「网络搜索」。会话输入框只显示勾选的模型，推理菜单按供应商提供的档位显示。来源是 `web/src/features/models/`、`konden/model_settings.py`、`konden/search/`、`thinllm/catalog.py` 与 `thinllm/responses.py`。

## 前置条件

按总技能启动隔离 Web 实例，Doctor 返回 0 后再操作。模型测试、搜索测试和 Bot 对话需要实际可用连接；不要改动日常 home 或共享凭据。连接状态只表示必要设置存在，不能代替一次真实调用。

## 驱动与判据

- **供应商目录**：打开「供应商与模型」，在「供应商」中选择账号；可用「搜索供应商模型」筛选并点击「刷新目录」。`GET /api/model-settings/catalog/{provider}` 返回该连接的可用目录与能力。目录读取不改写已选模型；失败显示「模型目录读取失败」和「重新加载」，不显示旧供应商的列表。
- **勾选与草稿**：点击 `在输入框显示 <供应商显示名> <模型显示名>`，到「已选模型」检查相同模型。保存前文件不变；「撤销修改」恢复最新已保存值。关闭抽屉、切换设置再回来保留草稿。
- **已选模型**：每行有默认推理强度、「测试 <供应商> <模型>」、更多设置与「删除 <供应商> <模型>」。修改上下文整理阈值后保存，`GET /api/model-settings` 与 `config.json` 一致。默认模型的删除按钮禁用；换新默认后可以删除旧默认并一次保存。仍被会话使用的模型返回 409，文件保持不变。
- **模型测试**：可用当前草稿的模型与强度发起测试，不要求先保存。成功显示「测试通过 · N ms」；失败显示原因并可重试。不同模型可以分别测试，切换页签保留结果和进度；改强度后旧结果清除。测试不改变默认模型、会话选择或连接文件。
- **网络搜索**：选择 DeepSeek 或 OpenAI。OpenAI 只有「搜索模型」，该列表独立于聊天勾选；不提供检索模式选项。「保存搜索配置」与模型设置分开保存。停用后服务和型号仍保留，测试禁用。`GET /api/model-settings/search` 对应隔离 home 的 `search.json`，不包含凭据。
- **搜索测试**：填写「测试问题」，点「测试搜索」。请求使用当前草稿，返回服务、型号、耗时、实际是否检索、回答与来源。DeepSeek 没有模型回答时只显示真实结果。OpenAI 固定自动选择工具，可能直接回答；页面显示「模型直接回答，未联网」，没有来源也不是失败。测试不发布草稿、不改变聊天候选。错误可重试；改变服务、型号或问题后清除旧结果。
- **实际搜索工具**：保存 DeepSeek 时只启用 `mcp:builtin-deepseek`；保存 OpenAI 时只启用 `mcp:builtin-openai-search`。停用后两者均不可用。用只读 `GET /api/capabilities` 对照，不使用该接口冒充页面操作；真实 stdio 装配由相关进程用例证明。
- **会话选择**：输入框旁 `切换模型：<供应商> <模型>` 的菜单只有勾选模型名称。推理菜单保留供应商原生档位。选择确认前不能发送消息，确认后才使用新选择。`GET /api/sessions/{id}/model` 返回 selected/effective/pending；`runtime_sessions/models.json` 为每个会话保存模型和强度。改变默认值只影响之后的新会话，正在执行的回复和 compact 保留已捕获的设置。

## 留证

桌面至少 1280×800，截图包括侧栏。保存同一状态的 `snapshot.txt`、`page.png`、只读 API 状态和 `note.txt`。窄屏可用 390×844 验证三个页签、控件与来源区域无页面横向溢出，完成后恢复视口。

## 注意

- `KONDEN_CONFIG` 只覆盖聊天模型配置，验证时不要残留指向日常配置的值。
- 凭据仍属于已有供应商连接；Web 不接收或回显密钥。Codex 独立授权可以续期，共享 Codex 登录只读。
- DeepSeek、StepFun、Codex 的档位来自目录。OpenAI 缺少的能力元数据只使用已确认协议事实，未知能力不猜测。
- 会话选择升级为完整记录，旧模型名称记录一次性转换后只使用新记录；损坏配置或元数据必须暴露错误。
