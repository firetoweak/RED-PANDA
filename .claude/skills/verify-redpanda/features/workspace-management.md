# 可选代码项目

代码项目是 Bot 可挂载的本地仓库目录，名称直接取目录名。创建 Bot 的同一表单可选目录，已有 Bot 在资料里 `关联项目` 或 `解除`；Bot 也能用 `link_project`。一位 Bot 可挂多个项目，同一目录可被多位 Bot 复用，各自的工作树在个人目录 `projects/<项目名>` 下。来源：`CreateAgentModal.tsx`、`ProjectDirectoryInput.tsx`、`LinkProjectModal.tsx`、`registry.py` 与 `/api/agents*`。

## Sub-features

- `create`：`新建 Bot` 同页填写 `名字`、`代码目录（可选）`，点 `创建`。目录为空则创建不挂项目的 Bot；不为空则在确认时校验 Git 仓库、复用或新登记目录并准备 worktree。不提供独立添加、项目命名或改名页面。
- `directory`：目录可手填、从已有候选选择或 `选择文件夹`；候选同时显示目录名和完整路径，同名目录据路径区分。选择窗口在后端所在电脑上打开，选完只填表单，不登记。
- `list`：`GET /api/workspaces` 为创建和关联表单提供候选目录；不生成侧栏项目分区。名称由目录名取得，不单独保存显示名。
- `link`：资料 `关联项目` 直接选 `代码目录` 后 `关联`，与创建表单共用选择控件。(a) `GET /api/agents` 该 Bot 的 `projects` 多一项，`directory` 是其个人目录下该项目分支的 worktree。(b) 弹窗关闭，资料与页头列出项目名。(c) 人检出不变；关联不请求决策。(d) 同一 Bot 重复挂载仍拒绝；非 Git 或无首提交目录拒绝且不登记。
- `unlink`：资料里项目旁 `解除`。有未结束的项目子协作、进行中的合并、未提交改动或未落地提交时拒绝并列明原因，原工作树和分支保留；成功时只移除这一位 Bot 的挂载，不影响项目和其他 Bot。

## How to get to it (user POV)

侧栏、首页 `新建 Bot`（空首页也有 `创建 Bot`）里直接选目录。已有 Bot 打开资料后点 `关联项目`，项目旁可 `解除`。

## Driving it with the browser

- **取消创建**：(a) 先填名字和目录，再关闭表单；`GET /api/workspaces` 和 `GET /api/agents` 均不增加。(b) 表单关闭。(c) 仓库内容不变。(d) 再打开不带上次草稿。
- **创建与复用**：(a) 新建 Ada 时手填 `$SCRATCH_WORKSPACE`，确认后登记一条名称取目录名的项目；新建 Lin 从候选选相同目录。(b) 两次 `POST /api/agents` 均成功。(c) 项目仍只有一条，两位 Bot 的 worktree、分支独立。(d) 不存在、非 Git 或没有首提交的目录给出具体原因，保留名字与目录供修改。
- **目录选择**：(a) `选择文件夹` 只回填路径，Bot 名字保留。(b) 取消不改原字段。(c) 确认创建之前没有项目登记。(d) 桌面不可用时显示后端原因并保留手填入口；等待人选目录不设超时。
- **后续关联与同名目录**：(a) 从已有 Bot 资料打开 `关联项目`，选择另一路径下的同名仓库。(b) 候选显示完整路径，关联后资料显示本 Bot 挂载名，重名时加序号。(c) 原有挂载和其他 Bot 不变。(d) 同一 Bot 再关联已挂目录时给出已挂载原因。
- **坏注册表**：(a) 非当前格式、重复 id 或重复路径令启动失败。(b) 暴露原始契约错误。(c) 不改写坏文件。(d) 不把损坏降级为空列表。
