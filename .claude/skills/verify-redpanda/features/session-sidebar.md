# Bot 名册

侧栏直接列出全部 Bot 与群聊，不按代码项目分区。来源：`AgentSidebar.tsx`、`BotRoster.tsx`、`AgentHome.tsx`、`CreateAgentModal.tsx` 与 `/api/agents`。

## Sub-features

- `create-agent`：侧栏或工作台的 `新建 Bot`；空首页还有 `创建 Bot`。同一表单填写 `名字` 与可选的 `代码目录（可选）`，目录可以手填、选已有记录或 `选择文件夹`。点 `创建` 才接入目录并准备个人工作目录和项目工作树；取消不登记。项目名取目录名，多个 Bot 可复用同一目录。Bot 名字全局唯一、区分大小写、禁止首尾空白。
- `switch` / `status`：点 Bot 名进入 `/sessions/<id>`，状态为 `干活`、`等授权`、`等人回话`、`空闲`；名字下显示负责方向。侧栏底部显示连接状态。
- `avatar`：Bot 使用无五官的抽象线条与柔和身份底色，按固定身份生成；名册、首页、会话、资料、群成员和 @ 候选保持一致。刷新、重启与改名不改变当前 Bot 的图形和颜色；历史消息只带旧名字且无法关联名册时，按该历史名字独立显示。 资料里的 `修改 <名字> 的头像` 打开八个随机候选，可 `换一批`、`上传图片` 或 `恢复默认`；保存后同一 Bot 的各处展示与其他已连接页面同步，上传失败保留原头像。
- `rename-agent`：会话顶部和 Bot 资料里的名字旁有铅笔；点击 `修改 <名字> 的名字`，编辑 `Bot 名字` 后 `保存`，或 `取消`。重名显示原因，空名与首尾空白不能保存。改名保留会话、项目、负责方向与群成员关系；侧栏和 @ 候选使用新名字。
- `edit-direction`：Bot 资料的负责方向旁有铅笔；点击 `修改 <名字> 的负责方向`，编辑后 `保存` 或 `取消`。空白不能保存，保存失败保留草稿和错误；保存成功后资料、会话顶部、名册与同事查询同步。人和 Bot 都可修改，按保存顺序生效。
- `search`：`搜索 Bot 或群聊` 按名称或方向过滤；清除恢复原名册和折叠偏好。
- `custom-sections`：`新建分组` 建本地分类，Bot 与群聊的移动菜单可归入分类；分组可以折叠、改名、删除，删除仅令条目回到 `未分组`。空名、重复名和保留名称不可用。
- `section-preferences`：分类、归属与折叠保存在浏览器 `redpanda.sidebarGroups`，不按代码项目隔离；搜索临时展开匹配分组。
- `home`：`/` 展示全部 Bot 与群聊；空首页显示 `创建第一位 Bot`，不自动创建会话。没有代码项目也能进入完整聊天流程；不再提供项目页。
- `navigation`：侧栏顶部直接 `新建 Bot`，`所有对话` 返回 `/`；没有品牌块、空间切换或独立的 `工作台` / `待处理` 按钮。有待处理事项时只在所属 Bot 的头像旁提示，进入对话处理，见 [inbox.md](inbox.md)。`对话类型` 提供 `全部` / `群聊` / `Bot` 过滤，Ctrl+K 聚焦搜索。

## How to get to it (user POV)

从侧栏 `新建 Bot` 或空首页 `创建 Bot` 进入；代码项目可不选。已有 Bot 直接从名册点名字。

## Driving it with the browser

前置只需模型可用与 SSE 已连接，不需 Git 仓库。

- **负责方向**：打开资料，点 `修改 <名字> 的负责方向`。空白禁止保存，取消保留原值；保存后名册、会话顶部与资料同步。再让 Bot 用 `declare_direction` 自行调整，随后用户再次编辑，最新修改应在真实模型上下文与同事查询中可见。切换 Bot 不残留上一位的方向；刷新、重启与窄屏资料抽屉中仍能查看和编辑。
- **创建与重名**：(a) 在空 home 创建 Ada，`GET /api/agents` 出现 `projects: []`，其个人目录存在。(b) 返回 201，进入 `/sessions/<id>`，侧栏出现 Ada。(c) 不新增代码项目或 Git 工作树。(d) 再建同名返回 409，弹窗说明 `已有 Agent`；空白名禁止提交，首尾空白请求为 422。
- **头像选择与上传**：(a) 打开 Bot 资料，点 `修改 <名字> 的头像`；八个候选与 `换一批` 可用，选择后 `GET /api/avatars` 保存对应 Bot 的生成种子；上传图片后保存图片引用，头像不成为会话消息或模型附件。(b) 名册、会话、资料与另一已连接页面同步，刷新和服务重启保留选择。(c) `恢复默认` 删除覆盖项，恢复该 Bot 原有自动图形与底色。(d) 上传伪装为 PNG 的非图片应显示错误、保留当前头像；390px 资料抽屉中仍能选择与上传。
- **改名**：(a) 分别从会话顶部和资料栏改名，保存后两个位置与名册同步；取消保留原名。(b) 名字撞其他 Bot 时给出原因，不能保存空名与首尾空白。(c) 刷新和重启后名字、会话地址、负责方向、项目与群成员关系保留。(d) 无项目和已挂项目的 Bot 输入区都没有文件改动条，不发起 `/changes` 请求。
- **删除 Bot**：从名册条目的 `<名字> 操作` 打开 `删除 Bot`，确认框说明停止范围和历史、目录、Git 成果保留；取消不执行。确认后 Bot 退出名册、待处理列表和群的有效成员，正在查看该 Bot 时回到所有对话，删除其他条目不改变当前会话。原地址仍能看到带原名字的只读聊天记录，没有输入入口；`GET /api/agents` 不再包含它，原 `GET /api/sessions/<id>` 的 `deleted` 为 true，`agent_name` 保留原身份。重启后仍不出现、不续跑，个人文件保留。
- **可选编码**：(a) 新建 Bot 时直接填写已有首提交的 Git 仓库目录，再创建另一个 Bot 并从目录候选中选择同一目录。(b) 名册的两条 `projects[].workspace_id` 相同，`GET /api/workspaces` 只有一条登记。(c) 两位 Bot 的个人目录、项目工作树与分支分别独立。(d) 无 Git 提交的目录不能完成创建；取消表单不新增登记。
- **状态与切换**：(a) 与 `GET /api/agents` 的状态、方向对照。(b) 在两个 Bot 之间切换，地址与聊天归属正确。(c) 不重新创建身份。(d) 查询不存在会话应提示不存在。
- **回首页**：从 Bot 对话点击（模型配置抽屉打开时先关闭抽屉） `所有对话` 回到 `/`；窄屏从展开的名册点击后自动收起。侧栏无 `工作台` / `待处理` 导航。
- **搜索与分组**：(a) 把 Bot 和群聊移入同一分类，刷新保留；搜索后清除恢复折叠。(b) 移动、改名与删除即时可见。(c) `GET /api/agents`、`GET /api/groups` 不受浏览器分类影响。(d) 空名、重名和 `未分组` 禁止保存。
