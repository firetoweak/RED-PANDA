# 会话文件变更审阅

输入框上方显示当前会话仍保留的净变更；点击摘要在右侧打开标题为 `文件改动` 的内容页（`ContentPage`，不是抽屉），选择文件查看旧、新行号和文本差异。来源：`web/src/features/conversation/FileChangesPanel.tsx`、`Conversation.tsx`、`ContentPage.tsx`、`web/src/api/fileChanges.ts`、`redpandaApi.ts`、`web/src/realtime/eventBridge.ts`、`redpanda/assistant/conversations.py`、`redpanda/filesystem/review.py`、`redpanda/channels/web/app.py`。

## Sub-features

- `summary`：输入框上方按钮，文字为 `N 个文件已更改`（加载中 `读取文件变更`，摘要请求失败 `文件变更暂不可用`），后接 `+a`、`−r`（只加总能够精确统计的文件；有不能精确统计的文件时再显示 `部分统计`）。按钮旁图标按钮 aria-label `刷新文件变更`。
- `content-page`：内容页 `section` 的 aria-label 与标题都是 `文件改动`；关闭按钮 `关闭内容页`；工具栏左侧显示所选文件路径（无选择时显示 `当前会话仍保留的净变更`），右侧为所选文件的 `+a −r`、第二个 `刷新文件变更` 图标按钮、`文件列表` 开关（`aria-expanded`）。
- `file-list`：侧栏 aria-label `改动文件列表`，标题 `改动文件 · N`；按目录分组（`details` 可折叠）。每个文件是按钮，名称 `查看 <path> 的差异`，`aria-pressed` 标示当前选中；按钮内显示状态字母 `A`/`D`/`M`（`新增`/`删除`/`修改` 只出现在字母的 aria-label 和按钮 title `<path> · <状态>` 里）、可精确统计时的 `+a −r`，以及不能精确统计时的 `部分`。打开内容页时默认选中第一个文件。
- `line-diff`：差异区 aria-label `<path> 的差异`；展示旧、新行号、`+`/`−` 和正文；旧行号无法确定的删除/上下文行显示 `?`。逐行来源标记：非助手来源的增删行标 `会话外`（external）、`混合`（mixed）或 `来源未知`。文件级提示：`partial` 时「部分统计：混合来源、二进制或不完整原文不计入精确行数；? 表示无法确定的旧行号。」；文件级 `origin=mixed` 时「包含当前会话之外的变化，请结合来源标记审阅。」；`binary` 时「二进制或非 UTF-8 内容，无法显示文本差异。」；属性变化（如权限）单独一行，会话外的标 `（会话外）`。
- `pagination`：每页 200 个展示行（含 hunk 标题与上下文），`上一页`/`第 N 页`/`下一页`，首页 `上一页` 禁用、`next_offset=null` 时 `下一页` 禁用；分页不改变完整差异的统计。文件 revision 变化时差异区重建，回到第一页。
- `refresh`：SSE 事件触发 `FileChanges` 缓存失效后自动刷新（`eventBridge.ts`）；两个 `刷新文件变更` 图标按钮手动刷新；差异读取失败时 Alert 内的 `刷新列表` 同时刷新摘要和该文件差异。
- `net-scope`：重复编辑不累加，恢复原值后移出列表；分支包含继承历史的原操作范围；其他会话的独立修改不计入本会话。

## How to get to it (user POV)

- 打开已有会话，在输入框上方找到 `N 个文件已更改`，点击后打开 `文件改动` 内容页；默认已选中第一个文件，可在 `改动文件 · N` 列表里点其他文件。
- 无变更时仍有 `0 个文件已更改` 入口，内容页显示 `当前没有保留的会话变更。`。
- 先按 `../SKILL.md` 检查隔离实例。通过编码回合准备变更时，`live_model_ready` 与 `sandbox.ready` 都必须为 true；任一不满足就记录未能准备真实成果，不用直接 POST 或伪造会话冒充页面证明。

## Driving it with the browser

前置：隔离工作区中没有 `review.txt`、`other.txt`。使用真实会话 A；涉及工具写入时明确授权。证据保存到 `$EVIDENCE_DIR/session-file-changes/`，不同状态用独立子目录保留截图、快照、只读响应和文件副本，不能互相覆盖。

- **定位控件**：页面上有两个 aria-label 同为 `刷新文件变更` 的按钮（摘要旁一个、内容页工具栏一个）。按名称点击时要限定容器（内容页在 `section[aria-label="文件改动"]` 内），否则会命中第一个或报重名。
- **摘要、列表与正文**：在 `消息` 中发送：`请用 write_file 新建 review.txt，UTF-8 内容为 first 和 second 两行，每行末尾都有换行；不要修改其他文件。完成后停止。` 等文件操作完成。
  - (a) 磁盘 `review.txt` 为 `first\nsecond\n`；`GET /api/sessions/<A>/changes` 仅一个文件，`status=added`、`origin=agent`、`added=2`、`removed=0`、`partial=false`。
  - (b) 页面无需手动刷新显示 `1 个文件已更改`、`+2`；点击摘要出现 `文件改动` 内容页，`review.txt` 已被选中（`查看 review.txt 的差异` 的 `aria-pressed=true`），状态字母 `A`（aria-label `新增`），新行号 1/2 及对应正文。只读 `GET .../changes?path=review.txt&revision=<摘要中该文件的 revision>&offset=0` 与页面一致。
  - (c) 读列表、点文件和翻页不改磁盘文件，也不新增模型决策或工具调用。
  - (d) 若显示 `文件变更暂不可用`（摘要请求失败）或内容页显示「无法读取文件变更，请刷新重试。」，先 Doctor；文件视图不可用时后端返回 503。确认实例正常后按提示刷新，不将警告当成零变更。
  - 临时差异读取失败后点击 `刷新列表`，应重新请求摘要及该文件差异；即使文件 revision 未变也应能恢复，不得一直显示缓存的错误。
- **会话隔离与净效果**：同工作区打开会话 B，让模型只创建 `other.txt`；回到 A。然后让 A 删除自己创建的 `review.txt`。
  - (a) A 不统计 `other.txt`，B 不把 A 的独立修改算作自身成果；A 删除后 `files=[]`，`added=removed=0`，`review.txt` 不存在。
  - (b) A 的摘要最终为 `0 个文件已更改`，内容页显示 `当前没有保留的会话变更。`。
  - (c) `other.txt` 保持 B 的实际内容。模型工具 `get_changes` 默认也采用会话范围，可交叉核对来源；显式工作区范围的查询不能代替此判据，工具调用也不能代替页面操作证据。
  - (d) 不以“最后一次工具改过文件”证明净变更；同一会话反复修改、最终恢复原值也应归零。
- **分页与旧结果失效**：让 A 创建 `review.txt`，包含编号 1 至 230，每行一个编号并带换行。点文件后用 `下一页`、`上一页`。
  - (a) 摘要始终新增 230 行；各页读取相同 `revision`，按 `next_offset` 续读覆盖全部正文。每页最多 200 个展示行，包含 hunk 标题与上下文，不能将页大小当作新增行数。
  - (b) 页码 `第 1 页` → `第 2 页`，正文变化；最后一页 `下一页` 禁用，首页 `上一页` 禁用。
  - (c) 分页与摘要统计分离；文件更新后使用新 revision 并回到 `第 1 页`。
  - (d) 保存旧 revision，让 A 再修改文件，随后对旧 revision 发只读差异请求 → 409（`文件变化已更新，请刷新后查看。`）；页面提示 `文件变化已更新或暂时无法读取。` 与 `刷新列表`，点击后可继续。不存在或已无当前会话效果的文件 → 404（`该文件已没有当前会话的变更，请刷新列表。`）；`path=../outside.txt` → 422（`文件路径必须是工作区内的相对路径。`），不读工作区外文件；不带 `path` 却带 `offset>0` 或 `revision` → 422（`续读时必须指定文件。`）。
- **外部修改与部分统计**：对 A 创建的文件，通过编辑器修改一行并保留其他助手内容，再点 `刷新文件变更`。
  - (a) 摘要含 `partial=true`；相关文件 `origin=mixed`、`added=null`、`removed=null`，不把会话外内容算作精确成果。文件级 `origin` 只有 `agent` 与 `mixed` 两种取值（`review.py`），逐行 `origin` 才区分 `external`/`mixed`/未知。
  - (b) 页面出现摘要 `部分统计`、文件的 `部分` 标记、「包含当前会话之外的变化，请结合来源标记审阅。」以及逐行 `会话外`/`混合`/`来源未知` 标记；无法判断的来源不标成助手。
  - (c) 查询不撤销编辑器修改，不改文件。
  - (d) 二进制、非完整 UTF-8 或原文证据不完整同样不得提供伪精确行数（二进制显示「二进制或非 UTF-8 内容，无法显示文本差异。」）；不把 `null` 显示成文件新增/删除零行——此时文件按钮和工具栏都不显示 `+`/`−`。
- **自动同步**：按 [realtime-events.md](./realtime-events.md) 的变更同步步骤，用两个标签页观察同一会话；保留工具完成后、无需手动刷新的摘要与 diff 证据。分支继承范围按 [edit-and-branch.md](./edit-and-branch.md) 的真实入口创建后核对，不能把继承成果错误地清零。

## Gotchas

- Coding Bot Agent（名册里的会话）不走上面的操作证据：列表是该 Agent 尚未落地的 Git 差异（已提交、未提交与未跟踪，不含被忽略文件），相对它与集成分支的分叉点；来源一律为 `agent`，不区分会话外修改。落地后列表清空；委派子任务的观察面板显示它尚未合入父分支的差异。判据：Agent 写一个新文件不提交，列表出现该文件且 Agent 工作树的 `git status` 不变；`land_branch` 后（先提交）列表为空。
- 入口名称：内容页标题是 `文件改动`，不是 `会话变更`；`会话变更` 只出现在空状态文字 `当前没有保留的会话变更。` 里。没有名为 `刷新` 的按钮，手动刷新是图标按钮 `刷新文件变更`（两处同名），`刷新列表` 只在差异读取失败的 Alert 中出现。
- 文件状态在界面上是字母 `A`/`D`/`M`；按可见文字找 `新增` 找不到，要用 aria-label 或 title。
- 此面板与模型工具 `get_changes` 默认均按当前会话查询（含分支继承）；工具显式 `scope=workspace` 才查询工作区所有会话的助手操作。工具允许已触碰文件显示 `external` 或 `unchanged` 以核对被覆盖、已恢复的内容，面板列表只保留仍有当前会话成果的文件。
- 净变更来自当前文件与实际操作证据，不等同于 Git HEAD 差异，也不累加工具调用次数。
- 二进制、混合来源与原文不完整的文件仍可在列表中出现；摘要只加总其他可精确统计文件的行数，并标 `部分统计`。
- 外部编辑没有自动监听，需手动刷新；文件操作失败也可能留下实际文件效果，仍需检查。
- 本入口只读，不提供接受、撤销或回退按钮；回退仍走 [file-rewind.md](./file-rewind.md)。
