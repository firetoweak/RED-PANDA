# 布局与外观

明暗主题、侧栏宽度、窄屏 Agent 名册、欢迎页与右侧内容页。来源：`web/src/app/App.tsx`、`web/src/main.tsx`、`ColorSchemeSwitcher.tsx`、`sidebarWidth.ts`、`ConversationWelcome.tsx`、`web/src/features/conversation/ContentPage.tsx`、`Conversation.tsx`。

## Sub-features

- `color-scheme`：侧栏底部图标按钮 `外观` 打开菜单（标签 `外观`），只有 `深色`、`亮色` 两项，当前项带勾；默认深色（`main.tsx` 的 `defaultColorScheme="dark"`），没有「跟随系统」。
- `sidebar-resize`：侧栏右边缘分隔条（`role="separator"`，名称 `调节侧栏宽度`，带 `aria-valuemin`/`aria-valuemax`/`aria-valuenow`），只支持指针拖动，无键盘调节；宽度夹在 220–520，默认 258，松手时写入 `localStorage` 的 `redpanda.sidebarWidth`。
- `desktop-columns`：PC 默认名册与聊天两栏，页头名字或 `显示 Bot 资料` 打开资料，`关闭 Bot 资料` 收起。资料保留状态、方向、项目、群聊与例行任务。打开文件改动等内容页时暂时让出资料栏，关闭后恢复。资料栏默认 288，在 1280 及以下为 256，1024 及以下改用抽屉；消息列表随聊天区展开，不再居中限制宽度。
- `message-spacing`：人靠右、Bot 靠左，正文都左对齐。作者与时间放在消息末尾，头像靠末尾对齐，状态与引用、复制放在署名下方并持续可见。气泡随内容收缩，最大正文 72ch 加左右内边距，代码不放宽整条底色，在内部滚动。同轮消息间隔 24；思考与执行入口在回复后并排紧凑展示，展开内容才占满详情宽度，各自保留手动展开状态。
- `mobile-sidebar`：视口窄于 `sm` 时侧栏收进 `打开 Agent 名册`。
- `welcome`：空会话保留 `折纸小熊猫` 与 `今天想一起完成什么？`；首页标题 `找一位 Bot，聊聊接下来要做的事。`，以列表列出全部 Bot 与群聊。零 Bot 时提供 `创建第一位 Bot` / `创建 Bot`，代码项目可选。
- `content-page`：子 Agent、文件改动、错误详情在右侧内容页打开，标题分别为 `子 Agent`、`文件改动`、`<标题> · 错误详情`；关闭按钮 `关闭内容页`；分隔条 `调节内容页宽度`（指针拖动或聚焦后左右方向键，默认 640、最小 320，PC 并排时给对话区至少保留 480，存于 `localStorage` 的 `redpanda.contentPageWidth`）。

## How to get to it (user POV)

- 侧栏底部 `外观`；侧栏右边缘拖拽；把浏览器窗口缩窄；在会话里打开子 Agent 或文件改动。

## Driving it with the browser

- **主题**：首次打开（清空 `localStorage`）后切到 `亮色` 并刷新，再切回 `深色`。
  - (a) 首次打开为深色；切换后 `localStorage` 保存了主题，刷新后保持所选主题。键名按 Mantine 默认 `localStorageColorSchemeManager` 推断为 `mantine-color-scheme-value`（本仓库未自定义，未在已安装的库源码里核对），以实际读到的键为准。
  - (b) 菜单只有 `深色`、`亮色`，所选项带勾；`<meta name="theme-color">` 亮色为 `#ffffff`、深色为 `#181818`。主题为中性灰，强调色保留小熊猫橙色。
  - (c) 服务端文件不变，不发任何 API 请求。
  - (d) 手动把该键改为非法值后刷新 → 页面仍能渲染（回到默认深色或 Mantine 的处理结果），记下实际行为。
- **侧栏宽度**：拖宽后刷新。
  - (a) `localStorage.redpanda.sidebarWidth` 为松手时的宽度，刷新后宽度保留。
  - (b) 分隔条的 `aria-valuenow` 随拖动变化。
  - (c) 主区域内容随之变窄/变宽，不被遮挡。
  - (d) 拖到极小/极大 → 被夹在 220 和 520；把该键手动改成非数字后刷新 → 回到 258。
- **窄屏**：视口 390×844。
  - (b) 出现 `打开 Agent 名册`，点开能切换 Agent，选完自动收起。
  - (c) 刷新后仍正常收起，不丢会话。
  - (d) 打开子 Agent 内容页（标题 `子 Agent`）后，输入框仍可用，`关闭内容页` 可点并关闭；内容页宽度被限制在可用宽度内。
- **欢迎区**：(b) 空会话显示 `折纸小熊猫` 与 `今天想一起完成什么？`；发出首条消息后欢迎区消失。首页从 Bot 列表打开私聊，无需代码项目。
- **Agent 资料**：打开会话或刷新后，`Agent 资料` 默认隐藏；点击会话页头中的 Agent 名字后出现，桌面再点同一名字收起。宽度 1000 和 390 时打开的是 `Agent 资料` 对话框，例行任务仍能查看、暂停、恢复和请求删除；`关闭 Agent 资料` 或 Escape 关闭抽屉，输入草稿保留。点执行记录的时间线跳转时抽屉自动关闭，能看到对应回复。运行状态更新不会自动打开资料。
