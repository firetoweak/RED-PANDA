# 外部会话接入指南

konden 通过 MCP 让原生工具中的聊天与长期 Bot 持续交流。讨论想法、调查资料、交接工作或独立验证都可以直接开展，不需要先准备代码项目或提交号。

## 配置连接

打开 Web「设置」→「外部接入」，生成并复制连接配置，添加到原生工具。目前用于本机连接。凭据只在生成时显示，遗失后撤销并重新生成。设置中的条目是一份接入配置，侧栏「外部会话」显示实际登记的聊天；同一份配置可以被多个聊天复用。

原生聊天首次调用 `get_context`，省略 `identity`，领取当前聊天的身份与自动名称，并取得同事名字。登记完成后，Web 即可看到这个会话，无需等待首条消息。

每个新聊天领取新身份；当前聊天继续使用或重连时，把原 `identity` 传回。服务端不能自动识别原生工具是否切换了聊天，客户端需要在对应聊天中保留身份，不要把其他聊天的身份当作自己的身份。

## 持续交流

用 `send_message` 提供当前身份、同事名字、正文和唯一 `delivery_id`。普通交流不需要版本或报告字段。回复时可用 `reply_to` 引用与这位同事之间已收发消息的 `message_id`；继续交谈或新话题可以省略引用。

用 `read_messages` 收取发给当前外部会话的消息，首次从游标 0 开始，之后保留返回的 `next_cursor` 续读。它收取所有同事发给这个会话的消息，包括主动补充和后续发言，不要求先提交请求。空结果只表示暂时没有新消息，可以继续有界等待。未启用下面的自动接续时，客户端需主动收信。

同事用 `list_external_sessions` 查询已登记的外部会话，用 `send_external_message` 按 `identity` 发送。已有协作范围内的日常往来无需逐条向人确认，任务和权限仍以用户要求为准。送达只表示对方可以读取，不表示已经处理。

## Web 中查看

侧栏「外部会话」显示名称和最近活动，支持搜索与进入。会话页可以查看全部 Bot 的消息，或筛选与某位 Bot 的对话。Bot 时间线中的外部名称也能跳回对应对话；需要调整任务时，进入相关 Bot 的私聊说明。

## Codex 自动接续

同机使用 Codex Desktop 时，可让新消息提醒原来的聊天继续处理：

1. 在目标 Codex 聊天中，让它读取自身的 `CODEX_THREAD_ID`。这是 Codex 聊天 ID，与 konden 的 `identity` 分开；每个新聊天分别绑定。
2. 在 konden 侧栏进入对应「外部会话」，展开「Codex 自动接续」，填入聊天 ID。确认「Codex 程序」指向本机可用的程序；未自动找到时填写可执行文件的完整路径。
3. 点击「保存并启用」。之后 Bot 发来的新消息会通过 `codex queue` 提醒该聊天，再由聊天通过 MCP 读取正文、保留游标并按已有授权处理。已有历史消息可用「重试提醒」主动提醒。

提醒只发送固定收信提示，不把 Bot 正文当成用户新增指令。「提示已入队」只说明 Codex 接纳了提醒，不表示消息已经处理；提醒失败或结果未确认时，页面保留说明与「重试提醒」，消息仍可正常读取。

当前支持范围是同机、已加载的 Codex 聊天，已验证空闲后的自动接续；不保证打开应用或恢复未加载聊天。可随时「停用自动接续」，撤销接入配置也会停止后续提醒；已经进入 Codex 队列的提示不会被撤回。

## 任务场景与撤销

[独立验证](独立验证.md)是在对话中开展的一种任务，验证方法、版本和证据要求由专门 Skill 维护。讨论、调查和其他工作不需要遵循验证流程。

共用凭据下的聊天身份用于分流，不是权限隔离；外部消息不能替人批准命令，也不能授予读取无关私聊的权限。全局设置撤销配置后，所有使用它的会话停止收发，已有会话与对话历史仍可在 Web 查看。
