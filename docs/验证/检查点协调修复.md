# 检查点协调与同步失败清理

2026-10-14，Windows x64，普通权限。处理[Git 检查点调查](Git检查点忙调查.md)发现的两个独立缺口：自动整理与显式同步互相竞争，以及同步失败后临时连接设置未恢复。

修复收拢在底层数据库连接边界，保留日常日志回收与严格同步的职责。没有另建后台服务、串行化全部读写或把忙错误当成成功；恢复连接设置失败时也不继续复用该连接。

验证主动制造检查点重叠、同步失败、设置恢复失败及 I/O 错误，检查等待、后续回收和原始错误传播。在隔离副本恢复旧行为时，对应回归按预期失败；修复版本通过。具体断言由[检查点契约测试](../../native/vfs/crates/vfs-core/tests/internal/checkpoint.rs)维护。

完整产品与原生回归、真实 Git 工作流、16 MiB 文件发布、WinFsp 挂载及六个中断时机的恢复验证通过。本机未执行 Linux FUSE。

这些结果关闭了上述两个缺口，不表示所有原因的检查点忙都被消除。外部读事务阻止严格同步时仍应明确失败，不能为了消除报错而降低持久化确认要求。
