# Windows VFS 接入验证

2026-10-09 起的历史接入记录。

这轮把文件视图接入真实 Worker 编码、命令执行、会话时间旅行和子任务成果合入，替代日常 Git 快照。Windows 上的真实模型编码与回退闭环通过；后续 Ubuntu 24.04 的文件发布、冲突、权限、符号链接及进程中断恢复专项也通过。

接入暴露了几类实际问题：Windows 内部元数据替换的瞬时占用、深层路径下的 Git 操作，以及叠层名称查询的重复工作。这些问题分别在对应边界修正，没有通过重跑用户命令或恢复旧 Git 快照路径处理。

保留的经验是：端到端验证必须同时检查命令结果、实际文件变化和宿主是否受影响。Worker 完成时间不能代替浏览器响应速度，平台专项通过也不能外推为完整系统隔离。

这一阶段之后，数据库执行层、底层历史机制和模块归属都有变化。设计取舍见[Agent 文件系统总览](../架构/Agent文件系统/总览.md)，运行与构建入口见[原生文件服务](../../native/filesystem/README.md)。
