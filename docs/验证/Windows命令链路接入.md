# Windows 命令生产链路接入验证

2026-10-14，Windows x64，普通权限。将[独立原型](WindowsHook原型.md)接入真实工具装配与任务执行器。

本轮验证的关键边界是：必要约束接入成功后才启动任务；正常结束、超时或取消时，先确认受管进程停止，再结束文件操作。命令自己的退出码不能被当作接入故障，接入失败也不能转到不受约束的任务入口。

真实工具验证覆盖 Node 文件操作、Clang 编译运行、Git 暂存与差异查询，以及中文和带空格的安装路径。取消验证直接检查子进程已退出，完整回归和接入专项通过。

Git 的非文件设备访问曾暴露错误分类，修正后复测通过；默认初始化当时仍受隐藏属性缺口影响，后由[隐藏属性修复](Windows隐藏属性.md)补齐。这两种问题没有通过 Git 特例或重试绕开。

验证范围是普通 Windows x64 开发工具与当时的 WinFsp，不包括对抗性绕过、全部工作区外副作用或其他平台的同等保证。约束设计见[命令文件视图接入](../架构/能力/命令文件视图接入.md)，运行入口见[原生命令组件](../../native/execution/README.md)。
