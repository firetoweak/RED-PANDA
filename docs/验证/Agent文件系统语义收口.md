# Agent 文件系统语义收口验证

2026-10-14，Windows x64，非提权；基于 `codex/filesystem-execution-windows-hook` 的 `a4ae646`，本轮修改尚未提交。

本轮核对的契约是：Agent 文件系统接受的显式修改必须有变化证据，并能参与发布和回退；当前没有恢复语义的操作，在产生变化前明确拒绝。文件系统继续独立于进程沙箱，与 Windows 命令 Hook 组合使用。

## 本轮修正

Windows 只读属性此前通过核心模式映射进入视图，但没有进入 Windows 变化证据。本轮贯通文件和目录的只读属性、查询归因、宿主发布、宿主撤销与视图回退。仅属性变化不捕获或重写内容；恢复属性时保留用户后来追加的内容，以及助手没有改动的属性。

向只读宿主文件发布已接受的内容修改或删除时，先核对对象身份和属性，再临时解除只读，完成后设置目标属性。中断后只在已知事务中间状态和同一对象上继续，不能把外部替换当成自己的写入。新建和覆盖文件也处理传入的只读、隐藏属性，不再忽略它们；不支持的创建属性在创建或截断前拒绝。

已有父目录因子文件写入而进入视图时，保留原权限与隐藏属性，避免隐式变成默认权限。POSIX 权限证据覆盖文件和目录，并把属性恢复与内容恢复分开；不需要内容证据的权限修改无需打开文件读取内容。

WinFsp 另有一处空缺：没有 `SetSecurity` 回调时，ACL 修改调用会返回成功。本轮增加明确拒绝的回调，真实挂载验证 ACL 和命名流请求均失败，原文件和变化证据保持不变。

## 支持范围

| 操作 | Agent 文件系统行为 |
|---|---|
| 普通文件内容、创建、删除与受支持的文件重命名 | 记录证据，按原有身份与冲突规则发布、回退 |
| Windows 隐藏与只读属性 | 文件和目录均记录、发布、回退；其他宿主属性保持原值 |
| POSIX 文件和目录权限 | 记录权限位，按独立属性恢复；Linux 挂载用例交由 CI 验证 |
| 所有者、显式时间戳、任务根元数据 | 变化前拒绝 |
| 目录重命名、硬链接创建、特殊文件创建 | 变化前拒绝；多链接文件删除和重命名仍沿用原有拒绝约束 |
| Windows 符号链接、ACL、备用数据流及其他不支持的属性修改 | 拒绝 |
| POSIX 符号链接权限修改 | 拒绝；符号链接本身沿用原有能力 |

Windows 普通创建和覆盖请求中的归档位作为系统提示允许通过，不承诺独立归档位修改；显式修改仍拒绝。内容写入自然产生的时间变化不承诺精确回退。底层 VFS 保留内部复制、物化与冻结所需的机制能力，不代表 Agent 操作开放相同范围。

## 格式与交付

底层数据库格式仍为 `0.13`，只读标记复用核心模式表示。变化证据新增必需的只读属性字段，旧证据明确拒绝，不做兼容层或自动改写已有会话存储。

原生文件服务和命令组件已重新构建，本地运行包重新生成；源码摘要、产物和运行包逐项校验通过，未遗留文件服务或 WinFsp 挂载。原始输出与校验值见[验证数据](Agent文件系统语义收口数据/metadata.json)。本轮未推送或发布运行包。

这次收口确立的是所声明文件操作范围的审计与恢复闭环。外部占用、身份变化、命名空间冲突和访问权限仍可能阻止发布或恢复；Windows Hook 的边界仍是普通开发工具接入约束，不是对抗性进程隔离，也不是完整 NTFS 语义。

## 后续能力声明校准

在上述完整回归后，进一步按产品取舍收窄环境提示、命令与恢复工具描述，并同步入口、执行环境和文件系统架构文档。这轮只修改能力声明，不新增文件操作、进程沙箱、提权、登录鉴权或多用户权限机制。

不支持的文件操作与未受约束的本机副作用分别描述：后者可能实际发生，却不能用文件回退撤销，不能写成系统已经拦住。需要当前没有的隔离保证时停止对应执行路径。UAC、sudo 密码与硬件确认不由命令工具承接；工具批准不代表系统提权或身份认证。Windows 的链接限制与 POSIX 基础符号链接能力分开表述，不承诺完整链接或 mmap 一致性。

Web 按本机个人入口说明没有登录鉴权和多用户隔离；不把工具批准按钮当成多人服务的安全边界。提示、工具 Schema、命令和架构边界检查 **38 项通过、21 项 process 用例未选择**；恢复工具检查 **2 项通过**。本轮未重跑前述原生和完整回归，追加校验的源码摘要与输出见[能力声明数据](Agent文件系统语义收口数据/capability-boundaries.json)，前面的完整回归及摘要保留其原始时点。
