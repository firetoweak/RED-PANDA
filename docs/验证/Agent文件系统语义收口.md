# Agent 文件系统语义收口验证

2026-10-14，Windows x64，普通权限。

本轮核对的是一个边界：接受的文件修改应能形成证据并参与发布和回退；没有恢复语义的操作应在变化前拒绝，不能仅让调用看起来成功。

修复覆盖 Windows 只读属性、POSIX 元数据证据、属性与内容的独立恢复，以及隐式父目录复制时的属性保留。另补齐了 Windows ACL 修改缺少处理时返回成功的问题，实际挂载验证其明确拒绝。

专项、完整产品回归、原生核心与 WinFsp 属性测试通过，验证包括保留用户后续内容、属性发布中断恢复和未支持操作拒绝。本机没有运行 Linux FUSE，新增 Linux 权限用例交由平台验证，不能把跳过算作通过。

过程中出现的 Git 检查点忙并未因后续多次跑通而关闭，随后单独完成[根因调查](Git检查点忙调查.md)、[SQLite 升级](SQLite升级.md)和[检查点协调修复](检查点协调修复.md)。

同时收窄了能力声明：文件回退不等于进程或网络隔离，工具批准不等于系统提权。支持范围不在本文另列一份，设计边界见[文件操作与回退](../架构/Agent文件系统/文件操作与回退.md)，具体行为以代码和测试为准。
