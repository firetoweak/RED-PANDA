# Agent 文件系统与命令执行拆分验证

2026-10-14，基线 `007ff9b`。本轮落实文件系统与执行能力的独立归属，保留现有读写分流。Windows 命令 hook 尚未接入，不能据此宣称宿主绝对路径写入缺口已经修复。

## 实际变化

Python 文件能力迁至 `redpanda/filesystem/`，命令、环境和受管任务进程迁至 `redpanda/execution/`。旧 `redpanda/sandbox` 包及总 Environment 绑定已删除，没有保留转发模块或旧导入入口。旧目录中残留的 Python 字节码归档在忽略的 `.tools/obsolete-sandbox-bytecode/`，不参与产品导入。

文件工具消费 `FileAccess`，命令工具分别消费文件访问与 `CommandEnvironment`。文件路径解析不再从执行附件中获取文件系统，工作区注册及宿主文件根发现也不再依赖命令 provider。`EnvironmentSelection`、`EnvironmentProvider`、`ExecutionAttachment` 及没有实际约束效果的网络、沙箱占位字段已移除。

Assistant 装配两类能力，Tools 负责参数和可观察结果。错误呈现从原执行 API 移至工具结果边界；模型可见的工具描述保持不变。架构检查同时覆盖绝对和相对导入，守住文件系统与执行能力互不依赖的契约。

原生文件服务客户端保留启动、通信和关闭文件服务的职责，不再启动任务命令。原先供原生契约测试使用的“开始操作、运行命令、结束操作”组合迁至 `tests/fixtures/file_view.py`；其中命令进程能力由执行模块提供。文件身份、文件句柄与删除操作保留在文件模块，进程启动和回收从原生文件适配中分离。

只读操作仍通过共享读取协调访问已发布宿主，不启动原生文件操作；可能写入的操作仍整次使用挂载视图，内部读写一致。操作实际变化、发布、恢复和子任务文件交换保持原语义。Host 的 Worker 管理与文件服务生命周期各自保留所属层。

## 原生交付

构建、安装、打包和 CI 的默认程序目录已迁至 `redpanda/filesystem/bin/`，显式程序选择变量改为 `REDPANDA_FILESYSTEM_EXECUTABLE`，不保留旧变量别名。相关使用说明和仓库验证工具的路径引用同步更新。

原生服务的 Rust 源码目录、程序及发布包仍使用现有交付名称，本轮没有修改原生协议或发布新版本。本机旧程序曾缺少当前 Python 所需的文件属性字段，已使用现有 LLVM MinGW、固定 Rust 工具链和已提取的 WinFsp SDK 离线重建 debug 程序。没有安装系统组件或修改系统环境。构建保留 WinFsp 外部头文件的既有警告。

重建后核对了 `BUILD.json` 中的源码摘要及全部交付文件摘要。Silo / Bind Filter 的历史实验仍按原程序版本保存，见[Windows 文件视图强制接入验证](Windows文件视图强制接入.md)，不能将本次重建当成那条路线已通过。

## 验证

| 验证 | 结果 |
|---|---|
| 迁移前默认回归 | 853 passed，3 skipped，167 subtests passed |
| 第一轮迁移后默认回归 | 853 passed，3 skipped，167 subtests passed |
| 原生文件视图、工作区及运行包专项 | 99 passed，21 subtests passed |
| 真实编码、文件回退及只读命令并发 | 3 passed |
| 导入边界、文件路径及装配契约专项 | 31 passed，1 skipped，5 subtests passed |
| 最终完整回归：`python -m pytest --all -q --tb=short` | 1060 passed，13 skipped，198 subtests passed；约 335 秒 |

首次完整回归发现 Windows 任务进程拆分遗漏 `CloseHandle` 声明，以及一处测试辅助导入混合了客户端和文件发布模块；均已修正，受影响专项已复跑通过。完整回归日志保存在 `.tools/filesystem-execution-all.log`。

最终完整回归还有 3 条 BytesIO 回收时的 BufferError 警告；此前验证已记录过同类警告，本轮没有定位其来源。收尾时 `fsptool-x64.exe lsvol` 成功退出且没有卷输出，没有残留的 `redpanda-sandbox` 进程，旧 Python 包目录也已不存在。完善相对导入检查后，17 项架构测试再次通过。

本机为 Windows；POSIX Bash、Linux FUSE 和需要符号链接权限的跳过项不算通过。本轮没有调用真实模型，也没有实现 hook、不可绕过的文件限制或完整沙箱隔离。后续接入继续遵守[已确认的命令文件视图方向](../架构/能力/命令文件视图接入.md)。
