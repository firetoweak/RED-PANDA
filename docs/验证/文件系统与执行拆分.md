# Agent 文件系统与命令执行拆分验证

2026-10-14，基线 `007ff9b`。本轮把文件历史与命令进程从原来的共同模块中拆开。

拆分的理由是两者变化原因不同：文件视图、审计与回退不应受进程沙箱的选型和生命周期支配；命令的启动环境、取消与进程回收也不应由文件系统接管。旧的总 Environment 绑定与转发入口随之移除。

验证保留了独立只读操作访问已发布宿主、可能写入的操作使用挂载视图的行为。文件发布、回退和子任务成果合入专项，以及完整产品回归均通过；导入边界检查守住两类能力互不依赖。

本轮只完成职责拆分，没有解决宿主绝对路径写入约束。该问题随后由[Windows 命令链路接入](Windows命令链路接入.md)处理，不能把拆分回归当作隔离能力验证。

当时本机为 Windows，Linux FUSE 和权限相关跳过项不算通过。现行边界见[Agent 文件系统总览](../架构/Agent文件系统/总览.md)与[执行环境](../架构/能力/执行环境.md)。
