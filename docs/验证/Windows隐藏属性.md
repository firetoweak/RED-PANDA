# Windows 隐藏属性验证

2026-10-14，Windows x64，非提权。修复默认 Git 初始化所需的隐藏属性，并将它贯通到 Agent 文件系统的变化证据、宿主发布和回退。未修改用户 Git 配置。

## 已实现的契约

隐藏属性是文件对象的独立元数据，与点号文件名无关。宿主已有的属性进入视图；修改只落在虚拟文件状态中；复制、重命名、硬链接和冻结制品保留该值。属性由核心存储，WinFsp 负责属性转换，Agent 文件系统负责操作归因及发布、回退。

仅修改隐藏属性时，证据不捕获文件内容，发布与回退不重写内容，也不更换已有宿主对象。助手没有修改的隐藏属性保留用户当前值；撤销属性修改时，用户后来追加的未观察内容保持不变。属性发布沿用已有事务记录，中断后仅在对象身份明确时继续。

只读属性沿用已有模式映射，宿主发布隐藏属性时保留只读、归档等其他属性。其他尚未支持的 Windows 属性修改和时间戳设置仍明确拒绝。本次不扩展为完整 Windows 元数据支持。

文件句柄可能在属性修改前打开，也可能从宿主直读内容；挂载返回属性时以核心当前属性为准，已验证活跃句柄与重新打开句柄的查询一致。

## 验证

- 真实 `execute_command` 入口经过 Windows Hook 执行默认 `git init`、`git add`、暂存差异查看，发布后的 `.git` 保持隐藏。测试隔离全局和系统 Git 配置，未设置 `core.hideDotFiles`；现有 Git 文件操作测试中的绕过参数已删除。
- 文件和目录的纯属性证据、宿主发布与撤销、视图回退与撤销回退、复制及重命名后重新打开、隐藏文件创建、只读与归档位保留均通过。
- 纯属性回退保留用户追加内容，两种策略分别覆盖宿主和视图路径；新目录属性发布中断后继续处理原对象。
- 原生核心覆盖隐藏属性的对象身份、硬链接、持久化和冻结，以及继承视图变化物化时的属性保留。WinFsp 实际挂载检查覆盖只读、隐藏属性、活跃句柄及不支持的属性拒绝。

最终全量回归 **1099 项通过、13 项跳过、198 个子测试通过**，运行 373.73 秒；有一条既有的 `BytesIO` 析构警告。收尾前文件、命令和回退专项 135 项通过；最终原生核心汇总 **192 项通过、2 项崩溃场景按默认忽略**，WinFsp 属性挂载检查 1 项通过。Rust 格式与两组 Clippy 均通过。

最终源码摘要、构建产物和两份运行包 SHA256 已逐项核对，未遗留原生文件服务或挂载。原始输出与校验值见 [验证数据](Windows隐藏属性数据/metadata.json)。Linux FUSE 与当前 Windows 无权创建的符号链接场景未计为通过。
