# Web

Web 是唯一常驻 Host 入口，前端经后端查询和操作应用，不直接读 Journal 或承担会话恢复。通用契约见[入口与授权](入口与授权.md)，状态所有权见[运行语义规约](../运行语义规约.md)。

## 使用边界与导航

当前面向本机个人使用，没有登录认证、多用户隔离或完整访问安全审计。连接身份和工具批准不能代替这些能力，不把现有入口当作可直接开放的不可信网络服务。

Bot 与群聊是日常入口，项目按需关联，不作为导航必经层。名册为空时先引导配置可用模型、创建第一位 Bot 并进入交流；这位成员与其他成员无区别，可改名和删除。名册不按项目划分，群成员也不受项目限制。

## 界面设计原则

采用“轻盈协作”，以舒适阅读和清楚身份承托长期交流。亮色白底、夜间纯黑底与中性灰气泡共享布局和阅读密度；轻边界、小圆角，静态气泡不加描边或投影，品牌色只用于必要操作与定位。具体样式参数以代码为准。

同一 Bot 的头像、署名与点名保持相同身份关系，不随主题交换。自动头像用抽象线条，不预设人格；人选定的头像随固定身份保留，刷新、重启与改名不改变它，也不把头像当作模型附件或任务输入。

私聊便于持续交流，群聊给完整报告留空间。人和 Bot 的气泡方向明确，正文左对齐；短消息贴合内容，长文保持舒适行宽，代码、diff 与表格在气泡内横向滚动，不撑宽页面。作者、时间和过程入口与正文分开，思考、过程按需展开，窄屏优先保留正文和输入。

操作有可访问名称、键盘焦点和触屏入口，不只依赖颜色或悬停。正文、错误与关键授权用文字说清，明暗主题都可读，使用本地系统字体并尊重减少动态效果偏好。

新来信不抢占历史阅读位置；切换聊天保留草稿、阅读位置和待发引用。引用能定位原文再返回，不自动点名、授权或创建线程；补全只填名字，中文输入法组合时不触发发送。送达标识依据真实记录，失败不能画成送达。

## 展示状态的来源

正式事实投影、会话瞬时活动与 UI 本地状态分别维护。正式投影按事实版本接纳，旧响应不能覆盖新事实；页面切换或重连后，旧确认不能重新声明当前选择。

运行预览和工具活动都可丢弃，刷新重读事实与 Host 当前状态，不跨服务重启保存。只有精确对应某条调用的活动能叠加为运行中，不能用整个会话活跃推断单个工具；来源丢失就回到事实中的未知，终态只能来自已提交结果。

进程失败和模型失败由 Host 的当前失败信息呈现，不能补写为工具结果。旧进程退出时结束旧运行展示、标明预览中止并重读事实；工具函数返回本身也不等于结果已经提交。

上下文用量来自当前窗口最近一次已提交模型调用，没有新窗口数据时保持未知，不沿用旧值或显示为零。定时倒计时只展示绝对到期时间，归零不证明模型检查完成；例行任务的安排与触发记录读取后端事实，浏览器不推算下一次触发。

## 对话与操作

长期 Bot 的普通回复直接给人看，过程与思考独立折叠；展开状态由用户选择，执行变化不强制覆盖。虚拟化只限制页面渲染范围，不裁剪历史事实或模型上下文。回复耗时表示消息到已提交回复的经过时间，包含工具与等待，不冒充模型纯计算时间。

运行中发送与空闲发送是同一种输入，接纳后立即进入历史，旧操作继续；相同输入重试只认回原消息。接纳失败保留草稿和错误。显式停止取消当前决策链、终止前台命令并回收子协作，不回退文件或隐式停止独立后台命令，见 [Runtime](../运行/Runtime.md#打断)。

当前未完成计划按需呈现，已完成记录留在相应历史，模型的事项状态不等于任务已验收。子协作的观察面板只读，不因查看而唤醒或选择子会话；子空闲与派出回执不作为完成证明，见[SubAgent](../运行/SubAgent.md)。

附件挂入后仍是草稿，发送才形成模型材料；失败附件留供重试或移除，不能悄悄漏掉。预览和下载以本会话引用为界，不能仅凭其他会话标识取得文件。本机文件选择发生在后端所在电脑，浏览器不提交任意服务器路径，文件读取与工作副本见[多模态附件](../上下文/多模态附件.md)。

## 设置与需要人介入的事项

模型配置、共同记忆与 Bot 个人资料按需编辑，只有明确保存才改变产品数据，关闭或切换设置保留当前页面内草稿；个人记忆不串用其他 Bot 的正文，规则见[记忆](../上下文/记忆.md)。

需要授权、确认、重试或交流超限时，在所属 Bot 旁提示并进入它的对话处理，不另设汇总工作台，也不把决定移入群聊。查看过不等于处理完。工具自动放行是全局选择，不能由当前页面或群选择改变；控制提案仍单独确认。

后台命令与子协作展示实际执行状态，例行任务提供意图、可读时间表、暂停来源和触发历史，可定位当次回复。人暂停的安排不能由 Agent 自行恢复；无人查看导致的暂停只恢复那次暂停的项目，详见[自动化](../运行/自动化.md)。

删除 Bot 或解散群前说明停止范围与保留成果，再由人确认。操作后移出日常名册，原历史只读可查，不再允许发言、授权或重试，不提供归档恢复。身份和保留规则见[成员身份](../多智能体/成员身份.md)与[群聊](../多智能体/群聊.md#提交恢复与人介入)。

## 群聊

群页读取公共群记录，成员发言可跳回对应 Bot，人发言可点名。回应调度与额度由 Host 决定，页面只表达事实，不等某位成员长工作结束再更新，也不用成员活动事件猜群讨论状态。

人的新发言转移讨论，停止执行在单个 Bot 中处理，不提供群级停止。群事实发生变化就重读群记录，不能靠历史正文重建调度；当前规则见[群聊](../多智能体/群聊.md)。

组件库只承担布局与视觉，不引入另一套会话 Runtime。前端缓存不参与后端恢复、授权或调度，也不恢复编辑旧消息开新会话、步骤回退等时间旅行入口。
