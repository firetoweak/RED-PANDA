# 模型与配置

用户操作见[模型配置](../../模型配置.md)，供应商调用边界见[Provider 接入](../能力/模型Provider接入.md)。本文只解释配置的归属与生效时机。

## 配置归属

个人数据根保存产品偏好、连接设置和运行资源；任务目录保存工作的文件，两者不能混用。多个独立实例必须分开数据根，工作区清单也不混进模型偏好或连接凭据。

供应商目录、用户勾选的聊天模型、新会话默认值、会话当前选择与供应商连接分别维护。读取目录不自动加入聊天模型，也不改变会话选择；推理档位遵循具体模型能力，未知能力不猜测。密钥不经过 Web；页面只展示必要设置是否齐全，不能据此推断认证有效或服务在线。缺少连接也允许启动配置页面。

[网络搜索](../能力/网络搜索.md)另存启停、服务与搜索模型，复用供应商连接；聊天选择不改变搜索配置，测试也不隐式保存两者。

## 会话选择与生效

模型与推理强度作为完整的会话偏好保存，不是执行事实；重放不重新调用模型，也不从事件流推导偏好。新会话捕获当时的默认值后独立维护，子会话捕获创建时父的选择；修改默认值不重写已有会话。

切换从下一次决策生效，在途决策使用原选择。模型、调用偏好与压缩阈值作为同一快照读取，不能在普通调用和启动压缩之间读到不同选择；已启动压缩仍用自己的原快照。

切换保留完整历史与工具结果，不自动裁剪上下文或转换历史。跨 Provider 只适配已经验证的协议差异，超限由上游明确报告。

## 连接与校验

聊天模型由用户从供应商目录勾选；目录不承担路由，也不把元数据复制成另一份偏好。默认值和会话选择必须引用已选模型，移除前解除引用，不把现有会话静默切换到其他模型。连接测试可使用未保存的模型与强度，不保存草稿、不改变会话。

偏好在决策边界读取，连接在调用边界热更新；在途请求继续持有自己的旧连接，应用不需要重启。非法输入在外部边界精确校验，损坏的持久配置与未知错误原样暴露，不能退回旧设置。

不做全局会话切换、模型推荐路由或跨供应商兜底。列表以外的模型先从供应商目录勾选，已废弃的环境凭据和全局模型选择路径不保留兼容层。
