# 外部会话协作

外部原生会话通过 MCP 与 konden 的长期 Bot 持续交流。当前聚焦同机 Codex，入口只接受它提供的原生聊天标识；其他客户端有实际需要时再适配和验证，不预建通用客户端框架。对话、身份与消息往返是基础能力，讨论、调查、交接和独立验证是在对话中开展的任务。入口复用 Web 所在的唯一 Host，原生工具继续拥有自己的上下文、执行环境与会话生命周期。

人从全局设置生成、命名或撤销接入配置；配置名称帮助人辨认设备或用途，不改变外部会话身份或权限，也不预选固定交接人。一份配置可以供多个原生聊天共用，会话身份直接取自客户端随调用提供的原生聊天标识；同一聊天继续或重连保持同一身份，不要求模型保存、领取或传回随机标识。共享原聊天上下文的子执行仍归属原聊天。标识缺失或无效时拒绝收发，不根据凭据、名称或正文猜测归属。可为会话命名以便人辨认，名称不参与路由。一个原生聊天同时使用一份接入配置；原配置撤销后可以换用新配置，身份、历史与续读位置保持，自动接续需重新启用。共用凭据下的身份用于分流，不构成权限隔离。

外部会话登记后即成为可查询、可寻址和 Web 可见的交流对象，不以发送首条消息为前提。它不取得内部 Bot 的执行身份、工作目录或人的入口身份。内部 Bot 名册继续描述长期 Bot；外部会话有明确的查询与联系方式，模型不需要猜测它是否属于内部名册。

Host 拥有外部会话的接入关系与身份登记，Bot 和 Web 读取同一登记。往返消息沿用既有 Bot 时间线作为事实源，外部会话页面按交流对象组织这些消息，不维护第二份聊天事实。新消息以稳定位置续读，重连与 Host 重启不改变已经接纳的消息、引用关系或续读位置。

双方都可以在用户授权的协作范围内继续发言或开始新话题，不依附某次请求才能回复。回复引用表达消息之间的关系，不代表任务状态或完成。外部端只能收取明确发给当前会话的消息，不能读取用户私聊、内部同事通信、工具结果或群历史。

建立接入表示允许 Bot 在已有协作范围内交换任务信息与结果，常规往来无需逐条确认；人后续提出的限制仍优先。外部消息是有明确来源的协作事实，不能代替人的指令、命令批准或其他授权，也不能授予披露无关私聊的权限。普通结尾文字继续给人看，发给外部会话的内容必须显式发送。

Web 在日常导航中呈现已登记的外部会话，并允许人查看其与各 Bot 的往返消息、联系相应 Bot。设置管理接入配置；新建必须经过命名与确认，取消不产生接入关系。人可以再次查看完整配置，因此凭据随本机配置保存，常规列表与模型上下文不包含凭据。状态分别呈现接入授权、主动收信或自动接续方式，以及提醒结果，不把登记、最近消息或一次握手成功解释成原生客户端持续在线。已撤销会话在日常列表收起，仍可搜索和查看历史。撤销配置后，使用它的外部会话停止收发，已有身份和对话历史保留。

消息接纳与任务验收分开。独立验证的需求、成果版本、证据与结论由参与者和验证 Skill 约定，其他任务不需要填写验证信息；Runtime 不做语义验收。相同投递标识重试只接纳一次，改动内容属于输入冲突。

MCP 提供发送与有界等待消息，原生会话主动读取并处理后续消息。同机 Codex 可由人在 Web 为单个外部会话启用自动接续，目标由已识别的原生聊天确定，人只确认是否启用和本机程序，不接受另填聊天目标；共用接入凭据不能代替单个会话的授权。配置与重试只由人的入口发起，外部消息不能指定程序或唤醒目标。

自动接续在消息接纳后向原生聊天发送固定收信提醒，正文与同事身份仍从 MCP 读取，不把 Bot 正文提升为人的新指令。消息事实与提醒结果分开：提醒失败不撤销消息，提示入队不代表客户端已运行或完成处理；无法确认的结果明确保留为未确认，停用与撤销停止后续提醒。该接入不接管原生客户端的执行生命周期，不承诺打开应用或恢复未加载聊天，也不扩展外部群成员或统一开发会话。
