# 入口与授权

Channel 把外部交互映射为会话操作，不拥有模型决策或执行循环。Web 是唯一常驻 Host 入口；TUI 是独立数据根的即开即用单会话，关闭即结束，不承载长期 Bot。[外部协作者](外部协作.md)通过 MCP 接入 Web Host，不能冒充人的入口。

## 身份与消息接纳

对话身份定位稳定 Session，消息投递身份保证同一输入只接纳一次，页面连接的选择身份只控制驻留和回复路由。三者不能混用，连接选择也不是命令授权。压缩只换阅读窗口，不换对话或入口路由。

输入的分类在同一应用操作内完成，不能先读状态、再由 Channel 猜测该提交哪种动作。明确的控制确认优先于命令批准，其余文本保留为普通用户消息；待授权时的其他句子不能被丢弃或解释成隐式批准。

运行和空闲期间的普通输入都立即接纳，不等待一轮任务完成，不插入当前冻结决策，也不创建特殊的运行中输入队列。后到消息见 [Runtime](../运行/Runtime.md#用户输入与后到消息)。

TUI 保留单会话的文本与控制入口，编辑输入可与执行并行，后台输出不能破坏编辑行；模型正文增量与提交结果对齐，不重复打印。已知模型失败可说明后继续接受输入，未知内部异常必须穿透到进程入口，不能打印后假装可以继续。

## 输出与展示

预览只属于当前连接，不写执行事实，也不证明模型结果已经提交。失败或旧 Worker 退出时，已显示的部分正文标成中止，不能提升为事实。

决策提交后，正式正文与预览按同一输出身份对齐，不重复显示。投递失败不回滚决策，也不重新调用模型或业务工具；入口只重试原输出。控制提案及其执行说明从自身事实投影，不另存一份权威结果。

选择会话失败保留原选择，关闭连接释放驻留声明；会话等待不直接决定进程是否退出。Web 只随创建 Bot 建立长期会话，不恢复普通会话列表或编辑旧消息开分支的入口。

## 命令授权

授权判定在命令签发时冻结，不产生副作用。文件写入先检查范围，明确不允许的目标不能让人批准成免检写入；实际写入前仍检查访问权限，批准不保证路径状态不变，也不扩大范围。

修改文件和每次启动命令都需要授权，只读文件工具不需要。命令文本不能可靠说明其效果，不按名称或前缀放行。子与父共享文件，写入和命令遵守同一授权，批准仍绑定实际调用；父委派或同事转述都不是人的批准。

自动放行是人维护的全局产品偏好，所有现有与新会话共用，不随页面选择变化，也不作为任务事实。真正允许派发的是对应命令已经留下的授权事实；总闸生效应及时反映到继续判断前，避免模型误以为仍在等人而重复发起操作。控制提案不受工具自动放行替代。

总闸关闭时，Web 逐个批准命令，TUI 的明确确认处理当时全部待授权命令。完整参数必须向人出示，无入口在线也不能替人改变选择或伪造批准。拒绝要与失败、超时明确区分，为调用保留配对结果，不把工具从模型能力中移除。

工具终态来自已提交结果。排队、待授权、拒绝与结果未知按对应事实展示；运行中只叠加精确属于该调用的瞬时活动，Session 整体活跃不能证明某个工具正在运行。结果未知不能被展示层推成成功或失败。

## 控制提案

安装、更新、启停和删除扩展使用独立控制提案，与普通命令批准分开，原因是人要审阅确定的变更对象及风险，不能只批准一个随后可能变化的操作意图。

提案请求先成为持久事实，只读准备不得改变安装、登记等产品状态。准备可得出无需执行的结论、明确外部失败或一个待裁决的确定提案；未知异常不能被包装成准备失败。候选确定后不静默重新探测或升级，人批准的是当时那份内容。

批准、拒绝、执行开始与执行结果分别记录。只有批准且执行开始已经提交，才可改变外部世界；执行已开始却无终态时保持未知，不自动重试。候选失效可明确失败，持久内容损坏仍原样暴露，不能补成普通失败。

同一请求的重试、裁决和投递只接纳一次。进程静止或重启不丢待确认项；已批准尚未开始的可继续，已经开始但结果未知的必须由相应领域核对，不能建设通用审批或恢复框架。

人看到操作内容、风险与裁决状态。模型只取得可观察的确认与执行结果，不需要理解内部候选、存储或调度机制。待人决定时不继续给模型提供新的控制操作，裁决终局再作为事实交回判断。

## 使用与安全边界

当前入口面向本机个人使用，没有登录认证、多用户隔离或系统提权。工具批准只控制操作是否执行，不能替代这些能力；本机命令仍能真实访问文件和网络，边界见[执行环境](../能力/执行环境.md)。

授权只从人的入口产生，协作消息、CLI 输出和外部内容不能授予权限。运行中的发送、显式停止与结果未知各有明确含义，不从文本或瞬时状态猜测。
