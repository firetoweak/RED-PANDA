# 会话模型选择

模型选择属于人的使用偏好。候选模型、新会话默认值、供应商连接和会话当前选择按各自变化原因分开保存。Web 提供候选配置页与会话输入区选择器，Runtime 不替人挑选模型。

## 所有权与生效边界

选择是会话元数据，不是 Journal 执行事实；重放不重新调用模型，不需要把偏好加入事件流。新会话捕获当时的默认选择，之后独立维护；修改默认值不会重写已有会话。分支与子会话捕获创建时父会话的选择。

切换在下一次决策边界生效，正在进行的 Step 继续完成。模型、调用偏好与 compact 阈值作为同一配置快照读取；不会在模型调用与上下文整理之间各自读取不同选择。后台 compact 保留它启动时的模型与调用偏好，后来的修改不改写已有任务。

完整历史与工具结果继续保留。跨 Provider 回放只采用已经验证的协议差异处理；不因模型切换自动裁剪上下文或做历史转换，超限由上游接口明确报告。

## 配置边界

候选列表由用户维护，不查询供应商模型目录。候选配置与手工编辑使用同一解析契约。新会话默认值必须引用候选模型；删除前须解除默认值和会话选择的引用，不把已有会话静默改到其他模型。

凭据与本地连接地址放在个人数据目录的独立结构化文件中，密钥不经过 Web。页面只展示必要连接设置是否齐全，不把它当成认证有效或服务在线的证明。连接未配置时仍可启动页面进行配置。

候选配置在决策边界读取，连接在调用边界热更新；应用不需要重启。在途请求与客户端的释放规则见[模型 Provider 接入](../能力/模型Provider接入.md)。非法输入在外部边界精确校验；损坏的持久配置和未知错误必须暴露，不能退回旧设置。

## 明确不做

不做全局会话切换，不做供应商自动发现、模型推荐目录、按能力路由或跨供应商 fallback。不允许在会话下拉中自由输入任意标识，新模型先进入候选配置。旧配置、环境凭据和全局模型选择路径在采用新设计时删除，不保留兼容层。
