# 上下文投影

上下文回答“这一次模型实际看到什么”，不拥有执行状态。窗口切换见[上下文压缩](上下文压缩.md)，图片与普通文件见[多模态附件](多模态附件.md)。

## 冻结一次判断

决策开始时冻结可见事实、稳定系统提示、已提交能力目录与工具契约，然后生成模型请求。静态规则在异步读取之前固定，动态内容只从冻结位置以内的事实投影；Journal 后来追加不能刷新当前请求。

能力已经在进程中加载，但成功结果尚未进入冻结事实时，对该决策仍不可见。产品登记变化也不能直接修改模型所见目录，必须先成为该会话已提交的更新。冻结后到达的新输入只影响后续决策。

用户、同事与群消息的接纳时间以紧邻正文的来源事实呈现，不修改原文，也不冒充发送方的发送时刻。实际请求、响应与用量留下可回查依据，但请求记录不能反向改写决策或成为当前产品配置。

## 保护窗与结果缩减

最近一条要求决策的外部事实之后，保留工具结果原文。这包括人的输入、同事请求、定时唤醒、子任务回传和控制操作终局；仅供观察的群抄送、目录更新、入群通知与进展提醒不移动边界。没有行动理由时，全部可见内容都处于保护窗。

较早结果只有在调用批次完整、成功且确被后续决策读取后，才可缩成引用。失败、尚未消费或不完整的普通大小结果保留原文；结果出现在旧调用旁边，不证明后面的回复已读过它，插话不能消费后来才到的结果。

外部唤醒推动保护窗向前，会使旧内容缩减、必要的前缀缓存失效。这是控制长期时间线增长的代价，不由系统判断旧结果是否语义上还有用。单条超大结果始终受外置边界限制，与年龄缩减分开。

## 原文与回读

过大结果完整保存在 Session 隔离的原件中，模型保留来源、必要预览、原工具提示与明确回读入口。结果移出保护窗后复用同一原件，不生成指向回读结果的新一层原件。

历史检索负责找到固定引用，内容回读负责按范围或关键词读取原文；关键词只作字面匹配，不语义排序。片段与续读范围使用同一坐标，不能把取得引用或片段说成读过全文。图片整件回读，与文本分页不合成同一种接口。

结果必须区分明确未执行、等待、确定结果和结果未知，保留已知中断原因与部分证据；报错或确认丢失不能证明没有副作用。控制、工作区绑定和压缩恢复所需的内部信息不作为模型消息，历史回查也遵守同一可见性边界。

## 前缀稳定性

系统提示只放稳定规则与会话内不变的环境事实，日期、名册、待返回委派、能力变化等动态内容以有来源的消息追加。工具说明只表达用途、参数与使用限制，不拼入最近失败或加载状态。

初始目录与之后更新形成顺序明确、可恢复的会话事实，不把最新目录每轮插回历史开头，也不重复追加未变化内容。工具定义按名称稳定排序，加载先后或并发完成顺序不能制造无意义变化。

排序不能保证真实工具变化后仍命中完整缓存。保持渐进加载，接受必要失效，不为缓存预先暴露全部能力。Skill 目录、正文与资源经消息按需供给，不把文字说明当作已经注册执行能力。

[记忆](记忆.md)与[工作计划](工作计划.md)遵守各自来源和追加呈现规则，不因优化前缀回填历史或引入第二份当前值。

## 用量与压缩

用量来自当前窗口最近一次已提交模型响应的实际输入，包含缓存命中，不累计历次调用或自行估算。用量与窗口一起留存，窗口切换后等待新的实际数据；投影器不按 token 用量拒绝模型请求。

不让 Runtime 做上下文缩减，不在调用前临时读取 Journal 尾部刷新本次判断，不把投影缓存当事实源，也不为未知事实类型添加序列化兜底。
