# Compact：后台交接与上下文窗口

同 Session 内的上下文窗口切换契约。投影脱水见[上下文](上下文投影.md)；提醒见 [LoopGuard](LoopGuard.md)；SYS／工具呈现见[前缀稳定性](上下文窗口与前缀稳定性.md)。为什么这样设计见 [Self-Handoff 实施设计](Self-Handoff实施设计.md)。

## 执行模型

```text
B 在安全位置 P 冻结当前模型输入
  ├─ B 继续业务，新增事实进入同一 Journal
  └─ 独立 H Worker：原 SYS / TOOLS / 消息 + 交接要求
       → 可多轮回读冻结来源
       → 非空文本且无工具调用 → 接纳 handoff

B 到安全位置 Q
  → 提交交接事实
  → 提交窗口切换事实
  → 下一次决策读取新窗口
```

B 的 Session identity、工具激活、委派和决策游标持续存在。H 有独立 Journal 和输入预算，不竞争 B 的 Step，也不继承其待执行 Command。H 使用相同的模型工具定义，但执行侧只允许回读 P 以内的冻结消息及其 Artifact；其他工具调用明确失败，不修改工作区、不发送用户回复。

B 可以是用户会话，也可以是尚未交回的子 Session。子 Session 沿用同一套容量检查、后台交接和窗口发布；H 继承的是该子在 P 处实际看见的输入，回读范围只属于该子。压缩不改变父子关系，也不把子过程带进父 Journal。

最终交接文本经一个不向模型暴露的内部 Command 接纳，不改变冻结工具列表。**`WAITING` 不是成功判据**——它也可能是在等工具结果；只有没有工具调用的非空文本才触发接纳。

## 窗口和来源

窗口发布位于直接工具及等待授权收口后的决策边界，不要求普通 SubAgent 全部回收——它们仍属于同一 Session。

新窗口必须保留 handoff、当前能力目录、`(P,Q]` 期间全部原样新增消息及之后的新事实。P 前的近期尾部只是有预算才保留的补充，不是发布前提。

近期尾部按 Event sequence / Step identity 选择最大的完整后缀。**一个单元是已提交 Step 及其直接 Command 结果**，不能拆开 tool call 与 tool result，也不使用"最后一个完整助手轮次"这种没有稳定 identity 的边界。选择时先应用既有外置与脱水，再受独立的尾部预算约束；最后一个单元仍放不下时尾部可以为空，由 handoff 承担接手信息——不能因为强制保留一条任意大的旧回合而让 Compact 失败。

Assistant 从 Journal 重建 active window。Runtime 始终归约完整 Journal：窗口隐藏的旧事件不被删除，也不会重新执行。

来源材料保存实际冻结请求、带事件序号的模型消息与允许读取的 Artifact。历史回读用事件序号，不把它冒充 Step 编号。handoff 保存原有证据强度，遇到疑点才回查，不做统一接班后验。

## 预算与恢复

容量检查与决策冻结使用同一 Journal 位置，并计入当次待追加的 LoopGuard 提醒。检查期间若有新输入、SubAgent 回报或窗口发布，旧检查结果不得用于包含新事实的 Step。位置约束由 Runtime 的通用推进前提校验，Runtime 不接收 Compact 相位或预算语义。

窗口发布先用输入硬预算校验稳定 SYS / tools、handoff 与 `(P,Q]` 新事实；近期尾部再以压缩触发线为发布目标使用剩余空间，避免新窗口一发布就再次触发压缩。必需部分超过触发线但仍在硬预算内时允许无尾部发布；超过硬预算才失败并保留旧窗口。

失败保留原始诊断，不自动重试、不发布半成品。B 容量足够时继续，容量不足时暂停模型调用但继续接收输入。压缩状态推给 Channel 展示，失败不冒充用户会话的模型失败。

子 Session 没有人能补充输入。若交接失败且子已无法在硬预算内继续决策，它以原始失败交回父 Agent，由父判断下一步；不能无限等待。子正常 `report`、静止交回或被 `reclaim` 后，未发布的后台交接作废，reader 停止；`subagent.return` 之后不得再发布窗口。已发布的窗口仍是该子 Journal 的历史事实。

发布顺序是：先保存交接 Artifact 和发布准备，再向 B 幂等追加交接与窗口事实，最后标记任务已发布。进程中断后继续同一次发布，不重新生成已接纳的 handoff；过期来源窗口不能覆盖当前窗口。

Host 侧的后台任务库只保存任务、结果和发布准备，不保存业务会话路由。开发阶段只维护当前表结构，不做版本检查与自动迁移；旧结构数据需停止任务后一次性备份重建。
