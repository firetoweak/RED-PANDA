# 个人记忆

个人记忆保存仅适用于单个 Bot 的工作约束：短、常用、常改、场景无关。它与[共同记忆](共同记忆.md)遵守同一准入原则、容量取舍和修订规则；知识结论、技能文档与任务记录分别归档、检索或由计划承载。

## 归属与维护

个人记忆跟随 Bot 的长期身份，改名、切换代码项目与压缩都不改变归属。正文位于产品数据中，与 Bot 可操作的项目文件分开。Bot 的记忆工具只读写自己的正文，用户可以在该 Bot 的资料中直接查看、编辑和清空。

个人记忆只保留对共同约束的必要补充，以及用户明确指定的个人例外，不重复复制共同正文，也不因作用范围更具体就自动覆盖共同约束。用户提出持续性约定或纠正时，Bot 可以在正常交流中修订；临时要求只作用于当前任务。

正文可以为空，采用较小的硬上限并整体修订。修改时以已读版本为基础，遇到用户或 Bot 的新修改先核对最新正文，避免覆盖未读内容。修改者与来源保留在操作记录中。

## 独立加载，保留原文

共同与个人记忆在一次判断前分别加载，作为当前请求的独立上下文放在历史之后，正文不作为观察事实追加到聊天历史。模型请求留有实际输入依据，既有历史不因记忆更新而改写。

压缩与交接不负责概括或恢复个人记忆，新窗口继续独立读取当前正文。记忆也不替代 Bot 身份、用户授权或历史记录。额外的主动检查与整理仍属于[未开始的方向](../未开始/记忆.md)。
