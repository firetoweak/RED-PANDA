# 记忆（暂不规划）

> 项目已定位为面向开发者的 coding agent，长期个人记忆不纳入当前产品规划。本文保留此前讨论的方向与约束，不是待实现事项；跨编码任务的知识复用须有具体需求后重新讨论，不按本文直接实现。

Memory 保存值得跨任务复用的知识。原始会话记录仍保存完整经历，记忆不取代它。

## 唯一硬约束

记忆由会话记录和产物提炼而来，**必须能指回来源**。它不能成为无法核验的第二事实源——这与 Journal 是唯一执行事实、投影不得反向拥有状态是同一条原则，见[运行语义规约](../运行语义规约.md)。

```text
会话记录 / 产物
        ↓
提炼并保留来源
        ↓
存储与检索
        ↓
一次决策开始时冻结检索结果
```

检索结果在一次决策开始时确定，和 Decision Context 同一个冻结边界，避免决策过程中模型所见悄然变化。

## 待设计

提取时机、记忆结构、更新规则和检索策略都未确定。
