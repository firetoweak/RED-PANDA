# 记忆的主动维护（未开始）

> 本文只保留尚未设计的主动维护方向，不按本文实现。记忆的现有边界见[共同记忆](../上下文/共同记忆.md)和[个人记忆](../上下文/个人记忆.md)。

记忆只承载短、常用、常改、场景无关的工作约束。知识沉淀归档后按需检索，任务进度由计划承载，过去的事情通过原始历史回查。

当前由 Bot 在正常交流中使用读写能力维护，用户也可以直接编辑。怎样补足 Bot 维护的主动性，由用户另行设计；不预先选定按回合、压缩或定时触发，不把检查次数或写入次数作为目标。

后续维护仍须由显式模型任务判断约束的含义、适用范围与修订依据，Runtime 只负责确定性事实和授权边界。维护不能扩大记忆容量、操作授权，或使记忆正文重新进入历史和交接摘要。
