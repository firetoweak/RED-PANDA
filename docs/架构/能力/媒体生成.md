# 媒体生成

媒体生成是可按需加载的独立能力，与 Bot 的聊天推理分开。当前支持 OpenAI 文字生图；操作见[图片生成配置](../../模型配置.md#图片生成)。

## 分层与归属

工具入口复用内置 MCP 的目录、加载、失效与恢复路径，只解释参数和可观察结果。媒体应用层拥有独立配置、工作目录中的原件交付与预览组织；供应商适配只处理 HTTP 协议、参数传递和已知外部错误。Runtime 不认识生图业务，聊天接口不承担媒体工具执行。

图片设置只记录启停与所选模型，连接文件仍是密钥的唯一来源。聊天、搜索、图片选择独立；更换聊天模型不改变图片服务，保存图片配置不修改聊天候选或连接。目录从当前账号读取，只提供选择依据，不证明调用权限或额度。

供应商协议变化留在适配边界。后续新增图片供应商可接入图片能力；视频的创建与查询另按实际异步协议设计，不要求同步生图先建立通用任务平台，也不为尚未接入的供应商定义占位实现。

## 调用与产物

每次调用读取配置和当前供应商连接，在途请求继续使用已取得的设置。停用移除能力目录中的可用项，已加载工具也不能绕过停用；更换模型后旧契约失效，沿现有 MCP 路径重新加载。

一次工具调用生成一张图片。原始字节完整保存到调用者工作目录，预览另行缩小并进入现有图片附件链路；历史只记录结果和附件引用，不保存协议编码，也不以预览替代原件。原图可沿已有文件交付能力发送，不建设第二套媒体资产存储。

已知认证、限流、供应商 HTTP 错误、传输中断和无效图片明确报告。付费生成不自动重试，超时不推断成未执行；未知内部异常、损坏配置和文件系统异常原样暴露。供应商已生成但调用结果丢失时，不凭本地缺少文件推断未发生外部副作用。
