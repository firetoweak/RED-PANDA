# 工具与能力

不同能力使用不同窄端口，不因都能供模型使用就合成插件框架。MCP 变化在协议和连接，Skill 变化在指令组织，CLI 变化在可组合的命令空间，基础文件与命令工具变化在执行面。

| 来源 | 提供什么 | 怎样使用 |
|---|---|---|
| 环境工具 | 最小文件与命令执行面 | 按会话执行环境直接装配 |
| MCP | 外部服务的工具契约 | 先看目录，按需加载后调用 |
| Skill | 方法与工作约定 | 读取指令，仍用已有工具执行 |
| CLI | 命令行程序与自己的配置、凭据 | 加载登记信息，再经 Shell 调用 |

## 归属与呈现

归属决定谁维护能力，呈现决定本次判断可调用什么，两者独立。外部能力各有自己的管理域，基础环境工具不因没有装卸生命周期而另建管理域；Runtime 只执行已绑定工具，不认识这些域。

扩展登记按数据根共享，不属于单个 Bot。跨进程修改必须基于完整的最新登记，不能互相覆盖，读取不能看见半次提交。会话怎样得知变化仍由各自目录事实决定，产品当前登记不直接改写模型已经看见的世界。

工具结果的领域内容由模型和对应适配器理解，Runtime 不猜结构化结果里的成功或错误字段。已知外部失败明确转换，未知内部异常原样暴露。文件改动直接生效，核对与完成判断见[执行环境](执行环境.md)和[工作计划](../上下文/工作计划.md)。

## MCP 的加载与恢复

模型先取得目录，成功加载成为已提交结果后，具体工具才从下一次决策可见。结果保留确定的契约快照，恢复可据此重建能力面，真正调用时才连接服务；内存激活集合只是缓存。

产品登记拥有当前安装、启用状态和凭据引用；Session 事实拥有它已看见的目录与加载结果。活跃会话在下次决策前、休眠会话在下次输入或恢复时取得变化，不扫描改写所有历史。已经冻结的判断保持原样，旧版本不可用须明确失败，不能静默换新版本；已加载契约也不随产品登记变化从会话历史中消失。

浏览器调试与自动化通过随产品提供的 MCP 接入，和外部服务共用加载与恢复路径，使用独立浏览器环境，不连接人的日常配置。内置能力随产品更新，不要求逐个 Bot 安装。

### 只读边界

受限会话只看见安装时由人声明为只读的服务，过滤目录而非事后按工具名称删功能。只读性属于确定的安装配置，不采信服务升级后可能变化的自报提示，也不让模型逐个猜工具风险。混合读写服务需要独立的只读配置。

连接测试可展示当前工具清单供判断，但不把会漂移的清单复制进产品登记。模型只获得过滤后的可用目录，凭据明文不进入目录或普通提案事实。

### 管理

管理工具按需加载，诊断只报告登记与实际连接事实，不从启用推断健康，也不代模型选择下一步。配置变更显式执行，不能借安装或恢复暗中覆盖；审批绑定确定版本，详见[入口与授权](../入口/入口与授权.md#控制提案)。

## Skill

Skill 是指令包，不增加工具执行循环或权限。目录只说明用途，正文和资源按需读取，不进入固定系统提示。内置方法、已启用安装包和工作目录中的 Skill 共用发现与读取方式；用户流程与适用的项目约定优先。

工作目录可携带自己的 Skill，不要求先登记 Git 项目；子协作沿用共享工作目录。包读取失败或结构不可用时仍给出身份与原因，不能让一份仓库内容使整个会话起不来。目录过长先压缩描述，完整呈现身份优先，不静默丢弃已发现能力。

目录变化沿用会话事实更新，旧内容变化后不能按旧版本悄悄加载新包。执行包内脚本仍是普通命令，需要原有授权，读取指令不等于得到许可。

安装包由产品完整持有，不长期指向任意外部目录。安装并启用是一项审批绑定的确定变更，更新保留原启用选择；信息查询只说明登记，包校验只证明结构完整，不保证内容安全或功能正确。管理帮助复用实际操作定义，不再建设一层激活或固定访问流程。

## 网上检索与表达

搜索优先使用用户启用的检索服务，再使用可用的内置 DeepSeek；它复用已有连接，与业务模型选择分开。连接变化在后续调用生效，不复制密钥或要求额外安装。浏览器可补充动态页面、交互和视觉证据，也可承担检索，不以搜索失败为使用前提。

模型按任务组合能力，Runtime 不自动改查询、选搜索引擎或隐藏失败。搜索命中、原文可读与事实已核实分别判断。图片和图表有助理解时可用，保留来源并区分证据与说明图；视觉细节必须实际查看，不能把链接或文字快照当作看过图像。

不提前展开全部外部工具，不把 Skill 当 Toolset，不把能力域放进 Runtime 调度，也不为这些端口建立统一插件基类。呈现顺序与前缀规则见[上下文投影](../上下文/上下文投影.md#前缀稳定性)，CLI 细节见[CLI 能力](CLI能力.md)。
