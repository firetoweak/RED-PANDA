# 网络搜索

网络搜索属于模型配置，搜索服务与聊天模型分别选择。搜索复用供应商连接，不保存第二份凭据；更换聊天模型不隐式切换搜索服务。配置、测试与实际工具使用遵循同一选择，停用后不再提供对应的搜索工具。

搜索能力通过既有 MCP 边界按需提供，Runtime 不决定是否搜索，也不在服务失败时隐藏地选择另一个供应商。模型根据可见工具、任务与证据选择下一步。

DeepSeek 提供网页搜索与原文读取。OpenAI 使用独立选择的搜索模型，由该模型自行决定是否联网；不在应用里配置额外检索模式。模型直接回答是有效结果，但不能冒充已完成的网络检索。搜索回答、检索摘要和网页原文保持各自的证据含义，来源链接随结果保留。

测试不保存草稿、不改变聊天选择。服务错误保留明确原因；未知异常与损坏配置直接暴露，不转成空结果或旧配置。
