# 执行环境

任务文件范围、命令环境与产品环境的边界。产品配置另见[产品配置](../运行/产品配置.md)。包职责与依赖禁令见[架构总览](../总览.md)。

本文规定工作区、任务文件视图与命令执行的接合。文件状态与操作历史归[Agent 文件系统](../Agent文件系统/总览.md)，执行隔离的接入方向见[进程沙箱](../未开始/进程沙箱.md)。

## 执行环境

执行环境绑定工作区文件范围和命令启动来源。工作区登记与路径范围描述任务使用的文件，不定义沙箱实例，也不规定沙箱生命周期。文件操作与恢复的规则见[文件操作与回退](../Agent文件系统/文件操作与回退.md)。

任务文件在该会话绑定的工作区主根，工作区开启完全访问时再挂上 Host 根。

任务根中的修改工具访问和可能写入的命令启动目录投影到独立候选文件视图，只读文件工具与声明只读的命令查询已发布工作区。逻辑工作区位置与临时挂载位置分离，模型和 Web 展示逻辑位置；读取与发布的互斥、文件变化及恢复由 Agent 文件系统管理，见[文件操作与回退](../Agent文件系统/文件操作与回退.md)。绝对命令参数、Host 根和材料根不因 cwd 投影而获得操作系统隔离。

上述分流以整次操作为单位：独立只读操作读取已发布宿主；可能写入的操作内部，任务文件的读和写都使用同一挂载视图，保证写后读取自己的修改。未修改的文件由 VFS 按视图语义从宿主基底读取，不把操作内的读请求单独切回宿主。

Windows 任务命令强制接入宿主拒写约束，覆盖只读与可能写入的操作；后者以挂载视图作为实际任务根，命令内读写同一视图。不要求原绝对路径透明重定向，也不承诺对抗恶意程序绕过。实际命令位置及失败后的可观察行为见[命令文件视图接入](命令文件视图接入.md)。其他平台尚未接入该 hook，不能据此宣称具有相同约束。

**Agent 不拥有工作目录**，Environment 描述的是"在哪里执行"，由调用方每次指定。

产品进程环境与工作区命令环境具有独立来源。Host 对产品内部工具补全本机环境，不改写工作区命令的启动来源；命令执行按给定环境查找 Shell，不猜测项目环境，见[多活跃会话 · 进程身份](../运行/多活跃会话.md#进程身份)。

RED PANDA 自身的运行依赖、内部工具及 CLI 管理使用产品环境。工作区命令使用独立的启动环境，不随产品工具的安装路径刷新而改变，不根据助手的解释器选择任务 Python。模型依据项目约定和用户要求选择解释器、环境管理器与执行命令；命令执行能力负责执行明确的命令，不判断项目语言或代替模型选择环境。

每次命令在请求目录中的新子 Shell 内执行，环境变更不改写 Worker，也不延续到下一次命令。用户指定环境是持续指导后续调用的会话指令，由模型在每次命令中落实，修改与取消仍由用户消息表达；上下文交接保留这一约束及其证据强度。初始化失败不擅自换用其他环境继续执行。

不建立工作区环境配置表、会话环境设置工具或环境管理器识别框架，不持久化完整进程环境来复现旧启动。已登记 CLI 经工作区命令调用时仍使用工作区命令环境，其安装管理不改变这条边界。本机执行仍不提供操作系统级隔离。

当前不提供进程、系统或网络隔离，也不约束所有工作区外写入。命令继承本机工作区环境，安装到用户环境、修改系统配置及访问网络可能真实生效，不能描述为系统已经阻止，也不能承诺用文件回退撤销。模型应获得这些可观察限制；任务要求当前没有的隔离保证时，应停止相应执行路径并说明能力缺口，不把文件视图视作完整沙箱。

命令只支持前台非交互执行，不承接 UAC、sudo 密码或硬件确认。需要这类交互的步骤由用户在工具外完成，用户告知完成后再检查条件；不增加命令内等待人工、自动提权或代确认通道。工具授权不授予系统权限，也不构成身份认证。

`RedPandaHome` 只表示产品自身的数据目录，**不能充当任务 Workspace 根**。工作区清单是独立的产品级文件，会话与工作区的绑定是一条会话级事实。

Session 已发送文件的材料视图可以作为独立只读根加入执行环境；这是窄材料入口，不把整个产品数据目录变成任务文件系统。只读由文件工具契约执行，本机命令不具备操作系统级隔离。原件不作为可写根，处理副本与产物由模型写入任务工作区，见[多模态附件](../上下文/多模态附件.md)。

Agent 文件系统与命令执行不依赖 Assistant、Runtime 或 Tools；Runtime 不认识文件版本、执行环境或沙箱；Tools 通过文件与执行能力的窄契约提供模型入口。装配层负责把指定的文件视图和命令执行接合，不将进程管理纳入文件系统。

文件工具直接消费文件范围、访问权限及当前文件视图，不依赖 Shell 或命令执行附件。命令工具分别消费文件访问与命令执行能力：前者解析本次启动位置，后者按给定目录和环境执行。工作区注册与宿主文件根发现属于文件能力，命令执行不据此反向管理工作区。不以没有实施效果的网络或沙箱状态字段表示已提供约束。

## 沙箱与生命周期

命令可以在本机执行，也可以由独立沙箱限制任务进程；整个系统也可以运行在部署方提供的外部沙箱中。外部沙箱可以在会话开始前建立、归档后销毁，无需与每条会话或工作区一对一绑定。这些组合不改变 Agent 文件系统的审计与回退契约。

执行环境释放时，先终止仍可能写入任务视图的受管进程并等待文件操作静止。临时进程、挂载与沙箱实例可以释放；需要保留的文件成果、审计历史和恢复依据按各自产品规则持久保存。当前没有实现沙箱的创建、接入或销毁流程，不预建通用沙箱接口。
