# 产品配置

产品个人数据、偏好与连接配置的所有权。任务执行边界见[执行环境](../Sandbox/执行环境.md)。

个人数据目录保存用户偏好、连接设置和运行资源。候选模型与新会话默认选择由用户维护，供应商密钥和本地地址单独保存；它们的变化原因不同，密钥不经过 Web。会话自身保存独立的模型选择，见[会话模型选择](../入口/会话模型选择.md)。

工作区有自己的资源清单，不混入模型偏好或连接配置。个人数据根可以整体更换；同一台机器并行运行多个实例必须分开数据根，见[自举开发](../../自举开发.md)。

配置在外部边界严格解析，消费者使用领域内部类型。模型偏好在决策边界读取，连接设置在调用边界热更新；首次缺少个人配置时创建初始文件，连接尚未填写也可启动 Web 配置页面。损坏的持久配置原样暴露，不采用旧值兜底。
