# 成员身份

一个 Bot 对应一条长期 Session，以全局唯一名字寻址，身份独立于项目。改名保留会话、目录与群关系，旧消息仍指向原身份，新通信使用新名字；曾用名不再分配。

Host 先持久建立身份再允许执行，名册由创建与变更事实重建，并发也须名字唯一。新成员先被同事知晓，再首次交互；通知不要求同事决策。模型查询当前名字、目录与可观察活动，变化按事实接续，不写进系统提示或暴露内部坐标。

角色与分工来自交流，不在创建时固定方向或提示词。约束放[记忆](../上下文/记忆.md)，经历查历史，知识按需读；新成员可直接向人问候与介绍，不设产品知识的专属成员。卡住或改派由模型判断。压缩后重述身份、群成员和例行任务，见[上下文压缩](../上下文/上下文压缩.md)。

删除使 Bot 永久退出，停止执行、子任务、命令和定时，拒收新工作。历史、个人目录与成果保留、只读可查，不自动落地、丢弃或恢复；名字仍属于原身份。
