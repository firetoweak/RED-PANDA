# 成员通信

## 私信寻址与送达

私信按当前名字寻址，可引用双方往来。发送确认进入对方时间线，不等待回复；Host 拉起离线成员处理，停止当前轮也不冻结后续协作。

## 通信边界与恢复

发言者、引用、因果来源和计数由事实确定，不靠模型自报。回复链限跳数，同一非 Agent 源头的消息还受总量限制，另起话题不重置；不同源头分别计数，超限拒绝并告知人，不从正文或时长猜闲聊。

未知发送按原身份核对收件方，已送达确认、未送达补投，恢复收口后才继续判断；不让模型换身份再发。损坏与身份冲突原样暴露。

同事转述不能代替人的授权。成员通信只给长期 Bot，普通 TUI、子 Agent 与压缩后台不取得成员身份。普通回复给人，给同事或群须[显式发送](交互与响应.md#普通回复给人协作消息显式发送)。

群消息的分发、成员发言与讨论推进见[群聊](群聊.md)。
