# 多智能体

本文说明长期身份、项目与通信。输入和回复政策见[交互与响应](交互与响应.md)，待解决问题见[后续方向](方向.md)。

## 稳定身份与名册

一个 Bot 对应一条长期 Session，以全局唯一名字寻址，身份独立于项目。改名保留会话、目录与群关系，旧消息仍指向原身份，新通信使用新名字；曾用名不再分配。

Host 先持久建立身份再允许执行，名册由创建与变更事实重建，并发也须名字唯一。新成员先被同事知晓，再首次交互；通知不要求同事决策。模型查询当前名字、目录与可观察活动，变化按事实接续，不写进系统提示或暴露内部坐标。

角色与分工来自交流，不在创建时固定方向或提示词。约束放[记忆](../上下文/记忆.md)，经历查历史，知识按需读；新成员可直接向人问候与介绍，不设产品知识的专属成员。卡住或改派由模型判断。压缩后重述身份、群成员和例行任务，见[上下文压缩](../上下文/上下文压缩.md)。

删除使 Bot 永久退出，停止执行、子任务、命令和定时，拒收新工作。历史、个人目录与成果保留、只读可查，不自动落地、丢弃或恢复；名字仍属于原身份。

## 项目归属与执行目录

![个人目录始终是 Bot 任务根，各自挂载独立工作树，通过落地与同步交换已提交历史](images/项目与工作树.png)

[可编辑图源](images/项目与工作树.svg)。挂载不切换任务根，模型按真实路径操作项目，实测见[项目挂载](../../历史/执行环境实测.md#任务根与项目挂载)。

个人目录持久存在，重启和压缩不改变；没有项目也能交流、处理文件和执行授权命令，普通目录不自动建 Git。项目按本地仓库登记，不重复登记每棵工作树；须已有首个提交，不接受无效根或裸仓库。人的目录选择确认后生效，模型指定新路径须人批准，引用已登记项目无需重复批准。Host 准备工作树与分支，调用方不指定内部目录。

首次集成基线来自人的已提交检出，后续不随人移动；不同数据根不争用集成分支。同事目录只读，放开其他宿主路径也不解除该边界，授权与隔离见[执行环境](../能力/执行环境.md)。

解除只删除自己的工作树与分支。未提交、未落地、合并未完或子协作未结束时拒绝解除；重挂从当前集成分支开始。准备与解除沿原操作收口，确认丢失先核对，恢复后再使用；结果不明不删除，清理不遮蔽原错误，外部 Git 环境与钩子不得改变项目归属。

## 编码方法与工作流

编码方法与 Git 协作分别作为 Skill 按需加载，用户流程与项目约定优先；个人目录也支持工作约定和自定义 Skill。Skill 提供方法，不授予能力、权限或固定流水线；项目工具负责工作树隔离，父子共享文件由父安排。

## Git 历史、落地与同步

Agent 决定提交范围、时机与验证，系统不在回合、压缩或重启时自动提交。提交使用 Bot 身份，不改用户配置；负责提交不等于获准推远端、改他人分支或重写历史。成果以实际提交为准，差异为空不证明从未修改。

图中的落地与同步由模型选择，Host 执行，同一项目集成修改串行；两者均单独调用，不与同一步其他工具并行。落地不逐次审批，不压缩提交，不触碰人的检出。

落地冲突放弃该次合并，集成不变；同步冲突留在自己的工作树，由 Agent 解决提交或放弃。覆盖风险阻止操作，不自动清理；其他 Git 错误不能统称冲突，也不保证失败现场未变。取消等操作收口，恢复只在能证明现场仍对应原合并时接续，不猜测外部修改。结果留在原调用事实，内部集成坐标不成为模型的操作负担。

当前无文件回退或对话分叉；Git 不覆盖忽略文件等全部副作用，见[AgentFS 的取舍](../../历史/AgentFS取舍.md)。

## 委派

[SubAgent](../运行/SubAgent.md)共享父的个人目录与项目文件，能看未提交内容，系统不另建工作树或自动提交集成。父安排范围、顺序与 Git 用法；子普通回复给父，过程不自动灌入父上下文。父验收文件和证据后显式回收，保留成果与历史，解除项目前须结束相关子协作。

## 私信与通信边界

私信按当前名字寻址，可引用双方往来。发送确认进入对方时间线，不等待回复；Host 拉起离线成员处理，停止当前轮也不冻结后续协作。

发言者、引用、因果来源和计数由事实确定，不靠模型自报。回复链限跳数，同一非 Agent 源头的消息还受总量限制，另起话题不重置；不同任务不混计，超限拒绝并告知人，不从正文或时长猜闲聊。

未知发送按原身份核对收件方，已送达确认、未送达补投，恢复收口后才继续判断；不让模型换身份再发。损坏与身份冲突原样暴露。

同事转述不能代替人的授权。成员通信只给长期 Bot，普通 TUI、子 Agent 与压缩后台不取得成员身份。普通回复给人，给同事或群须[显式发送](交互与响应.md#普通回复给人协作消息显式发送)。

## 群聊

![群发言先记录和分发，再独立请求指定成员回应，成员可显式引用消息发回群里](images/群聊分发与回应.png)

[可编辑图源](images/群聊分发与回应.svg)。成员仍在各自长期时间线工作，群按名字寻址，成员关系不依附项目。

调用时已到达的群记录共同可见。同一次回应只接纳一次，系统校验引用与待回应状态，不猜行动归属。继续报告或没有待回应请求的发言另起讨论并入队，不覆盖其他待叫成员。

Host 按轮数、回复量和源头总量限制互叫，不设主持模型。轮数用完可留发言但不再叫人，整轮无人发言则停。人的新发言取代当前讨论，不打断成员执行；没有群级强制停止，停止和授权分别在对应 Bot 的控制与私聊中处理。

发送与回应进度持久保存，重启按原身份补齐，不从正文重建派单。解散后停止发言与回应，不恢复旧讨论；历史只读保留，成员其他工作继续，群名不重用。
