# 多智能体

每位长期 Bot 有自己的 Session 和个人目录，既能独立工作，也能通过私信、群聊持续协作。项目按需挂载，不决定身份、群关系或分工。

共同修改代码项目时，长期成员各自挂载工作树；临时 [SubAgent](../运行/SubAgent.md) 共享父的文件，由父验收和回收。目标、职责与验收由人和模型决定，Host 维护身份、消息与确定的推进规则。
