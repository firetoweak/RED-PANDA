# 协作约定实验（2026-10-21）

本篇保留长期 Bot 协作约定改动前后的关键对照，不作为现行规则。现行约定与取舍见 [交互与响应](../架构/CodingBot/交互与响应.md#从长期处境组织提示)。

## 条件

每组在隔离数据根中新建 Ada、Lin、Mo 三位不关联项目的 Bot，使用本机 deepseek-flash 配置，经 Web 接口驱动，并开启自动放行。场景依次为：

- **准备**：人分别指定三人的负责方向，并让 Ada 在个人目录记下一条例会结论。
- **S-A**：人让 Lin 去问 Ada 评审截止日，再转告人。Ada 的记录里有这个答案。
- **S-B**：人让 Mo 去问 Lin 评审会地点。没有任何 Bot 知道这个答案。
- **S-C**：三人同在一个群，人在群里请每人各用一句话说出本周最要紧的事。

对照组为 `origin/main@ad809f0`，实验组在其上加入协作约定，每组各跑两次。

## 关键对照

| 指标 | 对照 1 | 对照 2 | 约定 1 | 约定 2 |
|---|---|---|---|---|
| 准备阶段的工具调用 / Bot 间私信 | 64 / 16 | 55 / 9 | 11 / 0 | 10 / 0 |
| 准备阶段的写文件 / 执行命令 | 11 / 11 | 10 / 10 | 1 / 1 | 1 / 0 |
| S-A 给人的回复：条数 / 字数 | 3 / 1209 | 3 / 653 | 3 / 321 | 3 / 238 |
| S-B 给人的回复：条数 / 字数 | 7 / 2366 | 3 / 589 | 5 / 737 | 6 / 582 |
| S-C 群发言 / 给人的回复条数 | 8 / 8 | 9 / 8 | 7 / 8 | 7 / 10 |
| 给同事的回答只写成普通回复 | 0 | 0 | 0 | 0 |

## 结论与限制

对照组在人只指定方向时，会自行打招呼、对齐分工、建立模板、探查环境。其中一次，Bot 被系统提示中「所在的群见对话中的记录」误导，以为自己应该在某个群里，于是用命令查找数据目录里的配置和数据库，想找出群名。加入约定、修正措辞后，这类自发工作基本消失。

给人的回复字数约减半。S-B 中两位 Bot 明确表示同事已问过人，不再重复询问。但回复条数没有下降：每一轮必须以给人的回复结束，被叫到群里而选择不发言的成员也会写一句「这轮不补充」，约定无法消除这些回复。

四次运行都未出现把给同事的回答只写成普通回复的情况。在这些样本里，显式消息工具一侧没有出现 `message_user` 实验中的遗漏，见[回复交付实验](回复交付1020.md)。

只测了 deepseek-flash，每组两次，样本小。群聊只测了一个话题。例行任务开始的一轮未测。驱动脚本和完整记录留在本机，未归档。

## 追加：允许无回复结束一轮

同日在协作约定之上追加一组试验。长期 Bot 的模型响应既没有文字也没有工具调用时，记为一次不回复的决策；普通会话仍按空响应失败处理。处境中「没有的话，用一句话说明你做了什么」改为「没有的话，不写普通回复，直接结束」。场景在 S-A 至 S-C 之后追加 S-D：人直接问每位 Bot 手上有哪几件事。

| 指标 | 运行 1 | 运行 2 |
|---|---|---|
| 选择不回复的轮数 | 0 | 0 |
| S-C 给人的回复条数 | 8 | 12 |
| S-D 回复了人 | 3/3 | 3/3 |

两次运行都没有出现不回复的轮次。可以沉默的那些轮里，有几位 Bot 在思考中写明「这轮没人问我，输出空内容」，实际却仍生成了一句文字，例如「（无需回应，Mo 这条不是在问我……）」。模型能判断该沉默，却不能可靠地产出空结尾；只要方案要求模型产出一种表示「不回复」的输出，就会受这一点限制。

另对照了两种相关做法，均未实测：

- 反编译重建的 Grok Bot 0.18 中，普通文字从不送达，人只能看到 `SendMessage` 的内容；Host 按唤醒来源设置 `isSilenceAllowed`，例行任务、其他 Bot 的消息和群成员轮次允许零输出；人开始的一轮要求先回一句，并在下一次调用模型前插入提醒，这些都是软约束。
- Deskfolk 让未点名的群消息只交给人确认过的负责人。

前者依赖模型记得调用回答工具，正是[回复交付实验](回复交付1020.md)中 deepseek-flash 做不到的；后者需要引入负责人角色。二者均未采纳。

结论：保持「一次决策必须有产出」与普通回复直接给人看，接受由同事、群或例行任务开始的每一轮都给人留一两句话。试验改动未合入。只测了 deepseek-flash，每组两次；更强的模型是否能产出空结尾、是否能稳定使用回答工具，未测。
