# 在外部对话中开展独立验证

独立验证是[外部会话协作](外部协作.md)的一种任务。用户继续在原生工具中开发，长期 Bot 从需求、真实操作与边界条件独立取证，把结果交回同一段对话，开发端处理问题后继续复验。

先完成外部接入，在 Web 创建承担验证工作的 Bot，并向它说明目标与已有权限。原生会话领取独立身份后，用普通消息联系它；可先讨论需求、确认环境，再交付可测试版本。

交付消息中写明验收需求、可获取成果的 PR 或仓库引用，以及完整 Git 提交号。版本与证据属于验证任务内容，不是通信工具的必填参数。开发端的实现说明、自测或 CI 结果只能作为背景，不能替代独立判断。

验证 Bot 按任务需要加载 `builtin:independent-verification`，从真实用户操作与边界形成验收判断，取得确切版本并记录证据。缺少环境、权限或明确需求时，向原外部会话提问或说明受阻。

验证过程与最终结论通过 `send_external_message` 交回对话，正文明确区分进度、必要问题与最终报告。报告说明通过、发现问题或受阻，提供实际测试的完整版本、可复查证据及未验证范围。发现问题时写清复现步骤、预期与实际表现。

开发端通过 `read_messages` 持续收取消息。取得问题后修复，交付新版本并引用原反馈或说明对应问题，再请求复验。双方沿用会话身份，回复引用用于接续讨论，不建立另一套验证通信通道。

消息已接纳、暂时没有新消息、普通进度或报告已发送，都不代表开发端已经修复或业务已验收。原生会话需要取得反馈、处理问题并交付复验版本，才能完成这轮协作。
