# 运行指南

首次安装与启动从[项目 README](../README.md#快速开始)开始。这里说明运行参数、模型配置和其他入口；开发环境由开发者自行选择。

## 运行环境

准备脚本自动下载运行所需的 Python，创建 `konden-env`，补齐应用工具、安装依赖、构建网页并初始化配置。已有可用的 Git、ripgrep、fd、Node.js 与 npm 会复用；缺少的便携工具保存在项目 `.tools/runtime/`，只加入应用进程及子进程的 PATH，不修改系统设置。这个环境只用于运行 konden，不代替工作区的开发工具链。

准备分四步：准备应用命令行工具、安装 Python 依赖、安装前端依赖并构建网页、初始化配置。Windows 缺少 Git 时使用便携 Git；Linux 引导需要 curl，缺少 Git 时通过 apt-get / dnf 安装，可能需要 sudo；macOS 需提前准备可用的 Git，终端命令与 Linux 相同。准备不安装驱动或其他系统组件，也不需要原生编译工具。

浏览器能力也是默认环境的一部分：准备脚本安装固定版本的 Chrome for Testing、Chrome DevTools MCP 与 Playwright。Bot 从能力目录按需加载 `mcp:builtin-chrome-devtools` 或 `mcp:builtin-playwright`，无需安装审批；具体工具从下一次决策开始可用。两项能力使用应用专用 Chrome 的独立无头会话，不读取人的日常 Chrome 配置，关闭后不保留登录状态。它们随产品更新，与用户另行安装的 MCP 分开管理；只读子 Agent 不提供这两项能力。

Linux 浏览器需要可用的系统沙箱。Ubuntu 23.10+ 等限制非特权用户命名空间的环境若报 `No usable sandbox`，可按 [Chromium 官方说明](https://chromium.googlesource.com/chromium/src/+/main/docs/security/apparmor-userns-restrictions.md)为项目下 `.tools/runtime/chrome/chrome` 的绝对路径配置 AppArmor 权限，允许该程序创建沙箱所需的用户命名空间。

### 准备选项

| 准备选项 | Windows | Linux / macOS |
| --- | --- | --- |
| 安装后在终端配置模型（默认在网页配置） | `-Configure` | `--configure` |
| 只检查项目所需系统工具 | `-Check` | `--check` |

参数传给 `scripts/setup.ps1` / `scripts/setup.sh`。检查模式仍会准备运行所需的 Python，但不安装项目依赖或初始化配置。

重复运行会补齐项目依赖并重新构建网页，已有配置保留。前端按锁文件使用 `npm ci` 安装，不改写锁文件。

## 日常启动与更新

按 README 中的 `scripts/start.ps1` / `scripts/start.sh` 启动，后端直接提供构建好的网页。浏览器打开终端打印的地址；默认端口为 `8765`。修改源码时使用 `scripts/dev.ps1` / `scripts/dev.sh`，支持 Python 与前端热重载。

启动命令复用现有环境，不安装依赖。拉取更新后，重新运行准备命令即可补齐依赖并更新网页。

### 启动参数

`start.ps1` / `start.sh` 会将参数传给 Web 服务。默认监听 `127.0.0.1:8765`；`--host` 指定监听地址，`--port` 指定端口。例如，在可信局域网内允许其他设备访问：

```powershell
# Windows
.\scripts\start.ps1 --host 0.0.0.0 --port 8765
```

```sh
# Linux / macOS
sh scripts/start.sh --host 0.0.0.0 --port 8765
```

其他设备使用运行机器的局域网 IP 和指定端口访问，例如 `http://192.168.1.10:8765`；`0.0.0.0` 是监听地址。服务没有登录鉴权，仅应向可信设备开放。查看全部参数可运行 `.\scripts\start.ps1 --help` / `sh scripts/start.sh --help`。

## 网页检索

网上检索优先使用用户已配置并启用的搜索 MCP（如 Tavily），其次使用已配置密钥的内置 DeepSeek。正文读取与浏览器可以组合使用：普通文字先读取正文，需要动态内容、页面交互、图表或截图时按需补充浏览器；未配置搜索服务时仍可通过浏览器检索。检索 Skill 提供来源核实与图文交付指引，已有材料足够时不为配图重复检索。准备环境不会调用外部检索服务，服务是否可用以实际调用结果为准。

### 使用 DeepSeek 搜索与网页读取

在当前数据目录的 `connections.json` 中填写 `deepseek.api_key` 即可；已有官方 DeepSeek 模型 API Key 可直接复用，无需另行安装、登记或运行配置命令，也不要求 Bot 使用 DeepSeek 模型。

配置后，Bot 在下一次决策时自动获得只读 `mcp:builtin-deepseek`，按需加载 `web_search` 搜索、`web_fetch` 读取原文。用户单独配置的搜索 MCP 优先，其次使用可用的 DeepSeek；浏览器可在检索成功后继续补充信息，无须等到服务失败。

搜索与模型调用使用同一份连接文件；修改密钥后下一次请求读取新值，无需重启，也不另存密钥副本。清空密钥后，DeepSeek 从模型可用的能力目录中移除；已加载的工具会明确提示缺少配置。能力清单不展示密钥，配置存在也不代表密钥有效或网页可读，实际调用结果才是本次证据。

两项接口按成功且有结果的请求次数分别计费，当前价格与参数限制见 [DeepSeek 官方指南](https://api-docs.deepseek.com/zh-cn/guides/search/)。搜索无结果、认证失败、余额不足、限流或网页不可读都会如实返回，由模型根据可见结果选择重试或其他来源。

## 模型与工作区

默认在网页侧栏「模型配置」中填写连接和模型，安装过程不等待 API Key。也可显式选择终端向导，填写供应商、API Key、本地服务地址（按需）、模型 ID 和 compact 阈值。API Key 隐藏输入；保存后可选择发送一条短请求验证连接。

之后需要重新配置时，在仓库根目录执行：

```powershell
# Windows
.\konden-env\Scripts\python.exe -m konden.initialize --configure
```

```sh
# Linux / macOS
./konden-env/bin/python -m konden.initialize --configure
```

也可以编辑 `~/.konden/connections.json`，并在 Web 侧栏「模型配置」中管理模型和默认值。连接设置在下一次调用时生效；Web 可以在未配置模型时启动。完整说明见[模型配置指南](模型配置.md)。

新建工作区、选择要处理的代码目录，再在名册里新建 Agent 开始使用。工作区必须是已有首个提交的 Git 仓库；每个 Agent 在自己的分支和工作树里工作，不碰你检出的目录，成果落地到这个项目的集成分支，何时合进你自己的分支由你决定。konden 的运行环境与工作区的开发环境相互独立；项目需要的 Python、Rust 或其他工具链由用户自行准备。

## 其他入口与数据位置

在仓库根目录，使用运行环境的 Python 执行对应入口：

| 入口 | 用途 |
| --- | --- |
| `web_chat.py` | Web 服务；`--host` 指定监听地址，`--port` 指定端口，`--workspace` 登记工作区 |
| `console_chat.py` | 即开即用的终端单会话；默认工作区为当前目录，`--workspace` 可指定；关闭后不保留会话 |

当前 Web 用于本机个人使用，没有登录鉴权或多用户权限隔离。工具批准只控制操作是否执行，不能用它代替登录保护；当前不支持直接把这个入口作为多人或不可信网络服务使用。

个人配置与会话数据保存在 `~/.konden`，应位于任务根之外。同一个数据目录同时只能运行一个 Web，第二个启动会报错并说明被哪个进程占用。测试独立实例时，可在准备与启动前设置独立的 `KONDEN_HOME`；`KONDEN_CONFIG` 可单独指定模型候选配置文件。详细说明见[模型配置](模型配置.md)。

终端入口使用自己的数据目录 `~/.konden-tui`（`--home` 可指定），不读取 `KONDEN_HOME` / `KONDEN_CONFIG`，与 Web 的数据互不相干；首次启动在终端里配置模型。同一目录同时只能开一个终端入口，每次启动都是全新会话。终端入口启动时会清空该目录里的会话与状态，因此 `--home` 不能指向 Web 用过、已有长期 Agent 的数据目录，否则会拒绝启动。

同时运行稳定团队与开发实例时，还要分开源码检出、数据根和端口，见[自举开发](自举开发.md)。
